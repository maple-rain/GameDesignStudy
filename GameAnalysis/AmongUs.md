# Among Us 게임 분석

## 1. 게임 개요
- 장르: 소셜 추론 / 파티 게임
- 핵심 경험: 제한된 정보 속에서 플레이어 간 심리전을 경험하는 것

## 2. Core Experience

플레이어는 단순한 미션 수행이 아니라 다른 플레이어의 행동을 관찰하고 의심하며 스스로 판단해야 합니다.

## 3. 재미 요소 분석

- 정보 비대칭
- 플레이어 간 대화와 심리전
- 정답이 정해져 있지 않은 추론 과정

## 4. 핵심 메커닉 분석

| 메커닉 | 설명 | 재미와 연결점 |
|---|---|---|
| 임포스터 시스템 | 역할에 따른 목표 차이 | 서로 다른 목표 충돌 |
| 회의/투표 | 정보 공유와 판단 | 사회적 추론 발생 |

## 5. 플레이 루프

행동 → 정보 획득 → 의심 형성 → 토론 → 투표 → 결과 확인

## 6. Problem Chaining

플레이어는 명확한 정답을 제공받지 않고 행동 패턴을 통해 문제를 정의합니다.

## 7. 제거/변경 분석

토론과 역할 비대칭이 제거되면 단순한 미션 수행 게임이 됩니다.

## 8. 디자이너 의도 추론

규칙보다 플레이어 간 상호작용이 재미를 만들어내도록 설계했습니다.

## 9. 기획자로서 배울 점

시스템이 제공하는 재미뿐 아니라 플레이어가 만들어내는 재미도 중요한 설계 요소입니다.
