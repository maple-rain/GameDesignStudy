> 분석 기록: [TIL - 모든 게임에 같은 질문을 던질 필요는 없다](../TIL/2026/08-26-BioShockInfinite.md)

근거 표기는 [Shadow Tactics](./ShadowTactics.md)에서 정한 3단계를 쓴다.

| 표기 | 근거 | 3단계 중 |
|---|---|---|
| `관찰` | 게임에서 실제로 일어나는 것 | ① 관찰 |
| `추론` | 왜 그렇게 만들었을지에 대한 가설. 확정된 결론이 아니다 | ② 설계적 추론 |
| `자료` | 개발자 발언이나 공식 자료로 확인된 것 | ③ 외부 근거 |

| 행동 | 레일을 타고 이동하다 특정 지점에서 뛰어내린다 |

## 5. 핵심 자원 (Core Resource)

### 1차 자원 — 소금, 즉 「이 게임다운 해법」의 잔량 `추론`

탄약이 아니다. 탄약이 떨어져도 다른 총을 주우면 되고, 총만 쏘는 플레이는 계속 성립한다. `관찰`

플레이어가 실제로 아끼는 것은 **소금**이다.

```
총기 전투    → 어떤 FPS에서도 할 수 있는 해법
능력 사용    → 이 게임에서만 할 수 있는 해법
그리고 후자만 소금으로 제한된다
```

**따라서 소금 잔량이 정하는 것은 강함이 아니라 해법의 종류다.** `추론`

> 이 전투를 **평범하게** 풀 것인가, **이 게임답게** 풀 것인가.

체력이나 탄약과 성격이 다르다. 없어도 게임이 진행되지만, 없으면 이 게임이 다른 FPS와 같아진다.

### 2차 자원 — 무기 슬롯 두 개 `관찰`

동시에 들 수 있는 것이 두 자루뿐이므로, 무기는 재고가 아니라 **선택**이 된다. `추론`

### 특이 자원 — 돈 `관찰`

성장 재화이면서, **실패하면 잃는 유일한 자원**이다.
이 항목만 다른 자원과 방향이 반대라서 8번에서 따로 다룬다.

### 근거의 범위

| 항목 | 근거 |
|---|---|
| 능력은 소금을 소비하고, 소금은 전투와 탐색으로 회복된다 | `관찰` |
| 무기는 두 자루만 소지한다 | `관찰` |
| 사망 시 돈을 잃는다 | `관찰` |
| 소금이 `해법의 종류`를 정하는 자원이라는 해석 | `추론` — 소금만이 이 게임 고유의 수단을 막는다는 점에서 역산했다 |
| 소금의 실제 수급량, 능력 없이 클리어가 가능한 난이도 구간 | **미검증** |

> **검증 방법**: 한 구간을 총기만으로 한 번, 능력을 적극적으로 써서 한 번 진행하고 소요 시간과 사망 횟수를 비교하면, 소금이 편의를 위한 자원인지 필수 자원인지 판정할 수 있다.

## 6. 플레이 루프

```
목표 달성을 위한 이동
  ↓
적과의 전투
  ↓
새로운 정보 획득
  ↓
다시 목표를 향해 이동
```

여기에 자원 루프가 겹친다. `관찰`

```
전투 → 탄약 · 소금 획득 → 다음 전투
```

**두 루프의 성격이 다르다.** `추론`

| 루프 | 진행을 만드는 것 | 플레이어가 얻는 것 |
|---|---|---|
| 이동 → 전투 → 정보 | **이야기** | 다음 장면 |
| 전투 → 자원 → 전투 | 시스템 | 다음 전투를 할 수단 |

그리고 아래 루프는 위 루프를 **유지시키는 역할**에 가깝다. `추론`
자원 루프가 단독으로 플레이어를 붙잡지는 않는다. 전투를 계속하는 이유는 자원이 아니라 **다음 정보**다.

[Monster Hunter: World](./MonsterHunterWorld.md)와 정확히 반대다. `추론`
그쪽은 이야기가 사냥을 위한 배치이고, 이쪽은 전투가 이야기를 위한 배치다.

## 7. Problem Chaining

**이 항목은 약하다.**

전투 하나 안에서는 짧은 판단이 있다. `관찰`

```
적의 종류를 본다 → 두 자루 중 무엇을 쓸지 정한다
→ 소금을 쓸지 아낄지 정한다 → 스카이라인으로 위치를 바꿀지 정한다
```

하지만 전투와 전투 사이에 조건이 이어지지 않는다. `추론`
한 전투를 어떻게 풀었는지가 다음 전투의 전제가 되지 않기 때문이다.

| 게임 | 진행 동력 |
|---|---|
| [Shadow Tactics](./ShadowTactics.md) | 해결이 다음 문제의 조건이 된다 |
| [Sleeping Dogs](./SleepingDogs.md) | 해금이 다음 선택지를 연다 |
| **BioShock Infinite** | **서사가 다음 장면을 연다** |

**문제 체인이 약한 것이 결함은 아니다.** `추론`
진행 동력을 다른 축이 담당하고 있을 뿐이며, 그 축이 무엇인지가 9번의 주제다.

## 8. 제거 / 변경 분석

### 죽음에 따른 돈의 손실

사망하면 돈을 잃는다. 그런데 돈은 업그레이드에 쓰는 성장 재화다. `관찰`

```
죽음 → 돈 손실 → 업그레이드 부족 → 이후 전투가 어려워짐 → 다시 죽음
```

**실패의 산출물이 음수인 구조다.** `추론`

[Failure Design](../MechanicStudy/FailureDesign.md)의 네 축에 대입하면 자리가 분명해진다.

| 축 | BioShock Infinite |
|---|---|
| 실패 비용 | 성장 재화 상실 |
| 원인 가독성 | 중간 |
| 실패의 산출물 | **없음. 오히려 다음 시도가 불리해진다** |
| 재시작 지연 | 짧음 |

저장소에 정리된 다른 게임들과 비교하면 이 조합만 성격이 다르다. `추론`

| 게임 | 실패가 남기는 것 |
|---|---|
| [Outer Wilds](./OuterWilds.md) | 지식 |
| [Katana ZERO](./KatanaZERO.md) | 그 방의 정보 |
| [Hollow Knight](./HollowKnight.md) | 잃은 자원을 되찾을 기회 |
| **BioShock Infinite** | **다음 전투가 더 어려워진다** |

### 그런데 판정은 중심축에 달려 있다

이것이 이번 분석의 핵심적인 지점이다.

| 이 게임의 중심이 | 그렇다면 이 요소는 |
|---|---|
| 전투 숙련이라면 | 긴장을 만드는 장치다. 신중하게 만들고, 회수 동기를 준다 |
| **서사라면** | **이야기를 보러 온 플레이어의 진행을 막는 마찰이다** `추론` |

같은 요소인데 판정이 뒤집힌다.
그리고 2번에서 확인한 이 게임의 중심은 서사 쪽이다. `추론`

**그래서 이 항목은 `제거 후보`가 아니라 `중심축과 어긋난 요소`로 적는다.**

### 남은 검증

| 항목 | 상태 |
|---|---|
| 사망 시 돈 손실이 의도된 설계인가 | **미검증** |

## 10. 기획자로서 배울 점

### ① 분석 프레임에는 중심축이 있다

이번 분석의 실제 산출물이다.

이 게임을 분해하는 동안 **행동 · 시스템 · 재미 요소 · 의도 어느 항목을 채워도 스토리와 세계관이 계속 끼어들었다.** `관찰`

처음에는 분석이 산만한 탓이라고 봤지만, 그것이 아니었다.

> **게임마다 플레이어 경험을 구성하는 중심축이 다르기 때문에, 같은 프레임을 대면 특정 요소가 다른 항목을 계속 침범한다.** `추론`

지금까지 써 온 순서는 이랬다.

```
플레이어 행동 → 시스템 → 반복 → 재미
```

이 게임에서 실제로 느껴진 관계는 이쪽이다.

```
스토리 / 세계관 → 플레이 동기 → 전투 → 탐색
```

**항목을 빼는 것이 아니라 순서를 바꾸는 것이다.**

### ② 「분석 불가」와 「축 이동」은 다르다

[Outer Wilds](./OuterWilds.md)에서 이미 한 번 비슷한 벽을 만났다. 다만 결론이 다르다. `추론`

| | 그때의 결론 | 이번의 결론 |
|---|---|---|
| Outer Wilds | **이 방법으로는 분석할 수 없다** | |
| BioShock Infinite | | **질문의 순서를 바꾸면 분석할 수 있다** |

앞의 것은 관찰 자체가 불가능했던 경우이고(직접 겪어야만 드러나는 게임),
이번은 관찰은 됐는데 **정리하는 틀이 맞지 않았던 경우**다.

둘을 구분하지 않으면 `분석이 안 된다`는 말이 두 가지 다른 상황을 덮어 버린다.

### ③ 그래서 분석 전에 중심축을 먼저 찾는다

게임의 핵심 재미가

- 전투 숙련인지
- 퍼즐 해결인지
- 시스템 조합인지
- 성장인지
- 탐험인지
- 스토리인지

에 따라 **어떤 질문을 중심에 놓을 것인지 달라져야 한다.**

지금까지 분석한 게임들에 적용해 보면 축이 실제로 갈린다. `추론`

### ④ 제거 판정도 중심축을 기준으로 한다

8번에서 확인한 것이다.

같은 요소라도 그 게임의 중심이 전투냐 서사냐에 따라 **긴장 장치가 되기도 하고 마찰이 되기도 한다.** `추론`

[Sleeping Dogs](./SleepingDogs.md)에서 만든 5개 층위는 `이 요소가 무엇을 담당하는가`를 물었다.
여기에 한 단계가 더 붙는다.

> **그 담당이 이 게임의 중심축을 돕는가, 방해하는가.**

### ⑤ 자원이 「강함」이 아니라 「해법의 종류」를 정할 수 있다

소금이 그런 자원이다. `추론`

없어도 진행되지만, 없으면 이 게임이 다른 FPS와 같아진다.

> 자원을 설계할 때 물어볼 것이 하나 더 있다.
> **이 자원이 떨어지면 플레이어는 약해지는가, 아니면 이 게임을 못 하게 되는가.**

### ⑥ 플레이어가 만드는 것에도 크기가 있다

계속 물어 온 질문에 이번에는 작은 답이 나왔고, 그것 자체가 정보다.

| 게임 | 플레이어가 만드는 것 | 크기 |

| [Hitman](./Hitman.md) | 사건 자체 | 상황을 구성한다 |
| [Dishonored](./Dishonored.md) | 통과 루트 | 방법을 고른다 |
| **BioShock Infinite** | **전투 방식의 조합** | **주어진 상황을 푼다** |

**만드는 것이 작다고 나쁜 게임이 아니다.** `추론`
