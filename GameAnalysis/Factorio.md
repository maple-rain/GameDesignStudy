# Factorio 게임 분석

## 1. 게임 개요
- 장르: 자동화 / 경영 시뮬레이션
- 핵심 경험: 생산 시스템을 설계하고 최적화하는 과정

## 2. Core Experience

작은 생산부터 시작해 점점 복잡한 시스템을 구축하며 성장하는 경험이 핵심입니다.

## 3. 재미 요소 분석

- 자동화 설계
- 최적화 과정
- 플레이어가 직접 만드는 목표

## 4. 핵심 메커닉 분석

| 메커닉 | 설명 | 재미와 연결점 |
|---|---|---|
| 생산 자동화 | 반복 작업 제거 | 효율 개선의 만족감 |
| 공장 확장 | 시스템 복잡도 증가 | 지속적인 성장 |

## 5. 플레이 루프

자원 확보 → 생산 설계 → 자동화 → 문제 발생 → 개선

## 6. Problem Chaining

플레이어가 시스템의 문제를 직접 발견하고 해결하도록 유도합니다.

## 7. 제거/변경 분석

자동화와 최적화 요소가 사라지면 단순 자원 수집 게임이 됩니다.

## 8. 디자이너 의도 추론

복잡한 시스템을 플레이어가 스스로 이해하고 확장하도록 설계했습니다.

## 9. 기획자로서 배울 점

플레이어가 스스로 목표를 만들게 하는 샌드박스 설계 방식을 배울 수 있습니다.
