# Hades

> 분석 기록: [TIL - 플레이어는 이 게임에서 무엇을 만들어내는가](../TIL/2026/08-11-Hades.md)
> **분석 기반의 한계**: 직접 플레이하지 않고 공개 자료를 모아 분석했다. 시스템의 존재와 수치는 자료에서 확인한 것이고, 전투의 감각과 선택의 체감은 검증하지 못했다. 이 문서에서 `추론`으로 표시한 항목은 확정된 결론이 아니다.

---

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 장르 | 쿼터뷰 핵 앤 슬래시 로그라이크 |
| 구조 | 지하세계 탈출 시도 → 실패 → 궁전 귀환 → 재도전 |
| 플레이 단위 | 한 번의 탈출(런). 4개 구역을 통과한다 |
| 반복의 성격 | 실패해도 영구 성장과 스토리 진행이 남는다 |

한 번의 탈출에서 얻은 은혜와 일시적 강화는 실패와 함께 사라진다.
그러나 **어둠, 열쇠, 스토리 진행, NPC 관계는 남는다.**
이 분리가 이 게임의 구조 전체를 규정한다.

---

## 2. Core Experience

> 반복되는 탈출 속에서 **이번 판의 빌드를 조립하고, 그것이 실제로 작동하는지 다음 전투에서 확인하는 것**

강해져서 적을 쓰러뜨리는 것이 핵심이 아니다.
같은 게임인데도 무기와 은혜의 조합에 따라 전투 방식 자체가 달라지고,
플레이어는 매번 **다른 조건에서 다시 조립**한다.

Factorio에서 잡았던 `내가 설계한 것이 예상대로 작동할 때의 감각`과 같은 계열이다.
다만 Factorio는 기계가 작동하고, Hades는 **내가 고른 조합과 내 조작이 함께** 작동한다.

## 3. 재미 요소 분석

| 재미 요소 | 이유 | 감정 |
|---|---|---|
| 즉각적인 전투 | 이동·공격·마법·특수·돌진을 조합해 직접 처리한다 | 손에 붙는 쾌감 |
| 빌드 조립 | 무기·양상·은혜의 조합이 매번 달라진다 | 이번 판은 무엇이 될까 |
| 실패가 다음의 재료가 됨 | 실패해도 어둠·스토리·관계가 남는다 | 손실이 아니라 진척 |
| 서사가 반복을 요구함 | 진엔딩까지 10회 이상의 탈출이 필요하다 | 다음 이야기가 궁금하다 |

**반복해서 수행하는 행동이 결국 전투이므로, 기본 전투가 재미있어야 반복을 견딘다.**
성장 시스템이 아무리 많아도 이 층이 무너지면 나머지가 작동하지 않는다.

## 4. 핵심 메커닉 분석

### 행동 메커닉

| 입력 | 행동 |
|---|---|
| WASD | 이동 |
| 좌클릭 | 공격 |
| 우클릭 | 마법 |
| Q | 특수 공격 |
| 스페이스 | 돌진 |
| F | 요청 (신의 호출) |
| E | 상호작용 |
| 1 | 동료 소환 |

### 시스템 메커닉 — 시간축으로 분류

시스템을 개수로 세면 일곱 개가 넘어 과하게 느껴진다.
그러나 **각각이 담당하는 시간축이 다르다.**

| 시스템 | 담당 시간축 | 결정하는 것 |
|---|---|---|
| 무기 | 런 시작 | 이번 판의 기본 전투 방식 |
| 양상 | 런 시작 | 같은 무기의 운용 방식 변화 |
| 은혜 | 런 중 | 빌드의 방향 |
| 방 선택 | 런 중 | 위험과 보상의 교환 |
| 기념품 | 런 직전 | 앞으로 등장할 보상의 풀 조정 |
| 거울 (어둠) | 런 사이 | 축적되는 영구 성장 |
| 동료 | 런 사이 → 런 중 | 관계로 얻어 전투에서 쓰는 제한 자원 |
| 형벌 규약 | 클리어 이후 | 플레이어가 직접 구성하는 난이도 |
| 신 모드 | 상시 | 실패 누적에 따른 진입장벽 완화 |

```
한 번의 전투를 위한 선택 → 한 번의 탈출을 위한 선택
→ 다음 탈출을 위한 선택 → 장기적인 플레이를 위한 선택
```

**의사결정을 네 개의 층으로 나눈 것이다.** 개수의 문제가 아니라 층위의 문제다.

### 자료에서 확인한 수치

```
피해량 = 기본 피해량 × (1 + 추가 피해량 총합) × (1 + 치명타 추가 피해량) × ∏(1 - 피해 감소량)
```

| 항목 | 값 |
|---|---|
| 무기 × 양상 | 6 × 4 = **24종의 전투 시작점** |
| 은혜 희귀도 | 6종 (일반 / 희귀 / 특별 / 영웅 / 전설 / 듀오) |
| 영웅 등급 | 단순 획득으로는 나오지 않는다 — 교체 선택지나 강화 수단으로만 |
| 전설 · 듀오 | 선행 조건을 만족해야 낮은 확률로 등장 |
| 신의 풀 | 올림포스 8 + 헤르메스 + 카오스. **한 런에서 올림포스 4명을 받으면 나머지는 등장하지 않는다** |
| 기념품 | 한 번에 하나. 25교전에 2랭크, 50교전에 3랭크 |
| 신 모드 | 피해 감소 20%에서 시작, 사망마다 +2%, 최대 80% |

## 5. 핵심 자원

### 현재 빌드에 맞는 선택지가 등장할 기회 `추론`

플레이어가 항상 부족한 것은 **강함이 아니라 원하는 조각이 나올 기회**다.

근거는 게임이 선택지의 공급을 여러 겹으로 조이고 있다는 점이다.

- 은혜는 3개 제시 중 **1개만** 받는다
- **올림포스 신 4명에게 받으면 나머지 신은 그 런에서 등장하지 않는다**
- 전설과 듀오는 선행 조건을 만족해야 낮은 확률로 등장한다
- 기념품은 이 풀을 넓히기 위해 따로 존재하는 장치다

**풀을 넓히는 전용 시스템이 있다는 것 자체가, 좁은 것이 기본값이라는 뜻이다.**

### 2차 자원 — 체력

런 안에서 실제로 소모되는 것은 체력이다.
회복 수단이 제한적이고, 카오스 방은 아예 **체력을 대가로 강력한 은혜를 판다.**
방 선택은 상당 부분 `체력을 얼마나 쓰고 무엇을 받을 것인가`의 교환이다.

> 두 자원의 관계: 체력은 **이번 판을 얼마나 버틸 수 있는가**를 정하고,
> 선택지는 **이번 판이 무엇이 될 수 있는가**를 정한다.

## 6. 플레이 루프

```
무기 · 양상 · 기념품 선택
        ↓
방 선택 (위험과 보상의 교환)
        ↓
전투
        ↓
보상 획득 → 빌드에 편입
        ↓
빌드 방향 재판단 ──┐
        ↓          │ 반복
    다음 방 ───────┘
        ↓
탈출 성공 / 실패
        ↓
궁전 귀환 → 어둠으로 영구 성장 · NPC 대화 · 스토리 진행
        ↓
다시 시작
```

**실패가 루프를 끊지 않는다.** 실패한 지점이 다음 루프의 입력이 된다.

## 7. Problem Chaining

```
1차   이번 방을 어떻게 클리어할 것인가
2차   어떤 보상을 선택할 것인가
3차   현재 빌드와 어떤 보상이 더 잘 어울리는가
4차   다음 지역을 고려하면 어떤 선택이 유리한가
5차   이번 탈출을 성공시키려면 빌드를 어떻게 완성할 것인가
6차   반복 플레이를 통해 장기적으로 무엇을 성장시킬 것인가
```

문제의 크기가 **한 방 → 한 구역 → 한 런 → 전체 플레이**로 커진다.
그리고 각 층의 답이 다음 층의 조건이 된다.

## 8. 제거 / 변경 분석

이 게임은 **단순 제거가 어렵다.** 시스템들이 서로를 참조하고 있기 때문이다.

| 후보 | 제거하면 | 판정 |
|---|---|---|
| 동료 | 전투는 돌아간다. 그러나 `NPC와 관계 → 친밀도 → 동료 → 전투 사용`이라는 서사와 전투의 연결이 끊긴다 | **제거 불가** |
| 기념품 | 능력치는 대체 가능하다. 그러나 **은혜 풀을 조정하는 유일한 수단**이 사라져 빌드를 의도적으로 노릴 방법이 없어진다 | **제거 불가** |
| 형벌 규약 | 클리어 전까지는 영향이 없다. 그러나 클리어 이후 목표가 사라진다 | **제거 불가** |
| 거울의 일부 강화 | 비슷한 종류의 전투 효율을 여러 층에서 조절하게 만든다 | **의심** — 선택의 의미가 실제로 다른지 확인 필요 |

**제거 판단의 기준을 바꿔야 했다.**

> `없어도 게임이 돌아가는가` 가 아니라
> **`이 시스템은 플레이어에게 어떤 새로운 선택이나 목표를 만들어주는가`**

이 기준으로 보면 대부분의 시스템이 각자 다른 시간축에서 목표를 하나씩 만들고 있다.
유일하게 의심스러운 것은 **같은 시간축 안에서 비슷한 일을 하는 항목**이다.

## 9. 디자이너 의도 추론

### ① 죽음을 실패가 아니라 서사로 만든다 `추론`

죽음이 `게임 오버`가 아니라 **탈출 실패**로 처리된다.
주인공은 지하세계의 왕자이므로 죽으면 집으로 돌아온다. 설정상 죽을 수가 없다.

**로그라이크의 반복이 시스템의 편의가 아니라 세계관의 일부가 된다.**
그래서 "왜 또 해야 하지"라는 질문이 "다음엔 무슨 이야기가 나올까"로 바뀐다.

### ② 실패를 반복할수록 쉬워지게 한다 `추론`

신 모드는 단순한 이지 모드가 아니다.
**사망할 때마다 피해 감소가 2%씩 오른다.**

실패의 누적이 곧 완화의 누적이므로, 못하는 플레이어일수록 자동으로 더 많은 도움을 받는다.
[Celeste](./Celeste.md)의 어시스트 모드와 같은 계열이며, **실패 비용을 낮춰 학습을 유도하는 설계**다.

### ③ 선택지를 일부러 좁힌다 `추론`

올림포스 신 4명 제한, 영웅 등급의 획득 경로 제한, 전설·듀오의 선행 조건.
전부 **주지 않는 방향**의 설계다.

전부 열어두면 매 런이 같아진다. 좁혀야 이번 판이 지난 판과 달라진다.
그리고 그 좁힘을 플레이어가 **기념품으로 부분적으로 되돌릴 수 있게** 해서, 통제권을 조금 돌려준다.

## 10. 기획자로서 배울 점

### ① 질문이 바뀌었다

지금까지는 `이 게임에서 무엇이 재미있는가`를 물었다.
이번에는 **`플레이어는 이 게임에서 무엇을 만들어내는가`**를 물었다.

| 게임 | 플레이어가 만드는 것 |
|---|---|
| [Factorio](./Factorio.md) | 공장 |
| [Slay the Spire](./SlayTheSpire.md) | 덱 |
| [Baba Is You](./BabaIsYou.md) | 규칙 |
| [Obra Dinn](./ReturnOfTheObraDinn.md) | 자신의 지식 |
| **Hades** | **빌드 · 루트 · 플레이 방식 · 목표** |

### ② 그런데 그것이 정말 플레이어가 만든 것인가

**선택지가 많다는 것과 실제 선택이 다양하다는 것은 다른 문제다.**

QA와 밸런싱을 거친 이상 강한 조합과 약한 조합의 차이는 생길 수밖에 없다.
모든 조합이 완전히 동일하면 오히려 `뭘 골라도 똑같은데?`가 되어 선택의 의미가 약해진다.

그렇다면 플레이어가 만드는 것은 **완전히 새로운 빌드가 아니라,
개발자가 설계해 둔 가능성의 공간 안에서 자신의 상황에 맞는 조합을 구성하고 발견하는 것**이다.

이 관점을 절차로 정리한 것이 [Possibility Space](../MechanicStudy/PossibilitySpace.md)다.

### ③ 시스템은 개수가 아니라 시간축으로 센다

`스펙업 요소가 일곱 개`라고 세면 과해 보인다.
`전투 / 런 / 다음 런 / 장기`라는 네 개의 시간축에 나눠 배치된 것으로 보면 과하지 않다.

**시스템이 많다고 느껴질 때는 개수를 줄이기 전에 시간축이 겹치는 것부터 찾는다.**
