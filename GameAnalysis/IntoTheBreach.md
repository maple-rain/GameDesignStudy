# Into the Breach

> 분석 기록: [TIL - 한 턴의 해답을 만들어내는 게임](../TIL/2026/09-22-IntoTheBreach.md)

근거 표기는 [Shadow Tactics](./ShadowTactics.md)에서 정한 3단계를 쓴다.

| 표기 | 근거 | 3단계 중 |
|---|---|---|
| `관찰` | 게임에서 실제로 일어나는 것 | ① 관찰 |
| `추론` | 왜 그렇게 만들었을지에 대한 가설. 확정된 결론이 아니다 | ② 설계적 추론 |
| `자료` | 개발자 발언이나 공식 자료로 확인된 것 | ③ 외부 근거 |

이 문서에도 `자료` 표기는 없다.

## 4. 핵심 메커닉 분석

### 행동 메커닉 `관찰`

메카 선택 · 이동 · 공격 · 공격 방향 선택 · 적 밀어내기 · 환경을 이용한 공격 · 메카 수리

**목록이 짧다는 점이 이 게임의 성격이다.** `추론`
할 수 있는 종류가 적은데 사고량이 높다는 것은, 복잡도가 **행동이 아니라 조합에서** 나온다는 뜻이다.

### 시스템 메커닉 `관찰`

적의 다음 행동 표시 · 턴제 구조 · 이동 범위 · 공격 범위 · 환경 상호작용 ·
시민 및 건물 보호 · 메카와 파일럿 성장 · 전투 후 보상 · 섬과 미션 선택 ·
다양한 적 타입 · 환경 디버프

### 메커닉 언어화 — 적의 다음 행동 표시

| 단계 | 내용 |
|---|---|
| 행동 | 턴이 시작되면 적의 예고를 확인한다 |
| 규칙 | 어느 칸을 어느 방향으로 공격할지가 전부 표시된다 `관찰` |
| 결과 | **미래가 이미 확정된 상태에서 턴이 시작된다** `추론` |
| 감정 | 이대로 두면 저렇게 된다 `추론` |

**이 시스템이 게임의 장르를 바꾼다.** `추론`

```
정보를 숨긴다 → 무엇이 올지 모른다 → 대비와 확률의 문제 (도박)
정보를 준다   → 무엇이 올지 안다   → 바꿀 수 있는지의 문제 (퍼즐)
```

### 메커닉 언어화 — 밀어내기

| 단계 | 내용 |
|---|---|
| 행동 | 적을 공격해 한 칸 밀어낸다 |
| 규칙 | 죽지 않아도 위치가 바뀌면 예고된 공격의 대상과 방향이 달라진다 `관찰` |
| 결과 | **공격이 피해가 아니라 결과의 수정 수단이 된다** `추론` |
| 감정 | 안 죽여도 되는구나 `추론` |

그래서 이 게임에서 `공격`의 정의가 넓어진다. `추론`

| | 공격의 의미 |
|---|---|
| 일반적인 전략 게임 | 적에게 피해를 주는 행동 |
| **Into the Breach** | **전장의 상황을 원하는 방향으로 바꾸는 행동** |

## 5. 핵심 자원 (Core Resource)

### 1차 자원 — 한 턴에 낼 수 있는 행동 `추론`

메카 3대가 이 게임의 자원이다. **체력도 탄약도 아니고, 몇 번 움직일 수 있는가**다.

그런데 이 자원이 사는 것이 특이하다. `추론`

```
일반적인 게임 — 행동으로 현재를 바꾼다 (적의 체력을 깎는다)
Into the Breach — 행동으로 예고된 미래를 바꾼다
```

적의 다음 행동이 이미 공개되어 있으므로, 턴이 시작된 시점에 **결과는 확정되어 있다.**
플레이어의 3번은 그 확정된 결과를 **수정하는 데** 쓰인다.

**즉 행동은 피해를 주는 데가 아니라 미래를 사는 데 쓰인다.** `추론`

### 이 저장소에서 정보의 자리가 처음 뒤집혔다

지금까지 분석한 게임에서 정보는 늘 **부족한 쪽**이었다. `추론`

| 게임 | 정보의 자리 |
|---|---|
| [Alien: Isolation](./AlienIsolation.md) | 부족해서 **공포**가 된다 |
| [Hitman](./Hitman.md) · [DEATHLOOP](./Deathloop.md) | 사서 모아야 하는 **축적 자원** |
| [Shadow Tactics](./ShadowTactics.md) | 관찰해서 얻는 **전제 조건** |
| **Into the Breach** | **공짜로 전부 공개된다** |

정보를 무료로 주면 **부족한 것이 행동 하나로 줄어든다.** `추론`
자원이 하나만 남으면 플레이어의 사고가 그 하나에 집중되고, 그래서 한 턴이 퍼즐이 된다.

### 자원의 크기가 곧 설계 변수다

메카가 3대인 것은 설정이 아니라 **조절 손잡이**다. `추론`

| 메카 수 | 일어나는 일 |
|---|---|
| 2대 | 여러 위협을 동시에 처리하기 어렵고, **해답이 없는 상황**이 생긴다 |
| **3대** | **해결은 가능하되 전부는 못 한다** |
| 4대 | 경우의 수가 크게 늘고, 동시에 여러 문제를 처리할 여유가 생긴다 |

세 번째 줄이 이 게임이 서 있는 자리다. `추론`

> **해답이 존재하되 쉽게 찾히지 않는 지점.**

### 난이도의 실제 변수 — 문제 수 : 행동 수

여기서 이 게임의 난이도 정의가 나온다. `추론`

```
문제가 너무 적다   → 해결이 단순해진다 → 고민할 이유가 없다
문제가 적당하다    → 해결책을 비교하고 순서를 따진다
문제가 너무 많다   → 해답이 없어진다 → 계산이 아니라 체념이 된다
```

**적이 강한 것이 난이도가 아니라, 문제와 행동의 비율이 난이도다.** `추론`

그래서 이 게임에서는 적의 체력을 낮추는 것이 난이도를 낮추는 방법이 아니다.
**문제의 개수를 줄이면 재미도 같이 줄어든다.**

### 근거의 범위

| 항목 | 근거 |
|---|---|
| 적의 다음 행동과 방향이 공개된다 | `관찰` |
| 메카는 기본 3대이고 한 턴에 쓸 수 있는 행동이 제한된다 | `관찰` |
| 밀어내기로 공격 결과를 바꿀 수 있다 | `관찰` |
| 핵심 자원을 `행동 횟수`로, 그것이 사는 것을 `미래의 수정`으로 보는 해석 | `추론` — 정보가 공개되어 있다는 전제에서 역산했다 |
| 실제 적 배치 수, 난이도별 위협 개수 | **미검증** |

> **검증 방법**: 여러 전투에서 한 턴에 등장한 위협의 수를 세고, 그중 몇 개를 막을 수 있었는지 기록한다. 대체로 `전부는 못 막지만 하나는 반드시 막을 수 있는` 범위에 있다면 위 해석이 성립한다.

```
  ↓                                  ↓
전장의 문제 파악                    보상
  ↓                                  ↓
가능한 해결책 탐색                  메카 · 파일럿 · 스쿼드 선택

```

안쪽 루프가 **한 턴 안에서 닫힌다**는 점이 이 게임의 리듬을 만든다. `추론`

그래서 조작이 단순한데도 플레이 밀도가 높다.

## 7. Problem Chaining

이 게임의 체인은 **한 턴 안에서 순서로 만들어진다.** `추론`

```
메카 A를 먼저 움직인다
  ↓
그 자리가 막히면서 메카 B의 이동 범위가 달라진다
  ↓
B가 적을 밀어낸다
  ↓
밀려난 적의 공격 방향이 바뀐다
  ↓
그 결과 C가 막으려던 공격이 사라진다
  ↓
C를 다른 문제에 쓸 수 있게 된다
```

**행동의 순서 자체가 변수다.** `관찰`
같은 3번의 행동이라도 순서가 다르면 결과가 달라진다.

| 게임 | 체인의 성격 |
|---|---|
| [Shadow Tactics](./ShadowTactics.md) | 해결이 다음 문제의 **조건**이 된다 |
| [DEATHLOOP](./Deathloop.md) | 하나를 정하면 나머지가 **제약**된다 |
| **Into the Breach** | **행동의 순서가 가능한 수를 바꾼다** |

앞의 둘은 시간이 걸리는 체인이고, 이것은 **한 턴 안에서 즉시 닫히는 체인**이다. `추론`

## 8. 제거 / 변경 분석

### 파일럿과 스쿼드 성장

퍼즐형 게임에 성장 요소를 넣으면 균형이 깨질 수 있다. `추론`
5번에서 정리한 대로 이 게임의 난이도는 **문제 수와 행동 수의 비율**로 만들어지는데,
성장이 행동 수나 위력을 늘리면 그 비율이 무너진다.

[Sleeping Dogs](./SleepingDogs.md)의 5개 층위와 [BioShock Infinite](./BioShockInfinite.md)의 중심축 검사를 적용한다.

| 층위 | 해당 여부 |
|---|---|
| 핵심 게임플레이 | **그렇다** — 쓸 수 있는 해결 수단의 종류를 정한다 |
| 성장 시스템 | 그렇다 |
| 공간 / 세계 경험 | 아니다 |
| 장식 / 분위기 | 부분적으로 |

중심축 검사에서 이 요소의 성격이 드러난다. `추론`

중심축은 `제한된 행동으로 한 턴의 해답을 찾는 것`이다.
그런데 스쿼드와 파일럿이 바꾸는 것은 **행동의 양이 아니라 종류**다. `관찰`

```
행동 수를 늘린다     → 문제 : 행동 비율이 무너진다 → 퍼즐이 쉬워진다
해결 방법을 바꾼다   → 비율은 그대로 → 같은 문제가 다른 퍼즐이 된다
```

**따라서 제거 후보가 아니라 비율을 건드리지 않는 방식의 재미 확장이다.** `추론`

플레이어가 `이 파일럿과 어떤 메카가 맞을까`를 고민하는 것도 같은 이유다. `관찰`
성장이 강해지는 문제가 아니라 **푸는 방식의 문제**이기 때문이다.

### 남은 검증

| 항목 | 상태 |
|---|---|
| 스쿼드 간에 실제 난이도 차이가 얼마나 나는가 | **미검증** |

> **검증 방법**: 같은 섬을 서로 다른 스쿼드로 두 번 진행하고 클리어 여부와 피해량을 비교한다. 차이가 크다면 종류가 아니라 강함을 바꾼 것이고, 그렇다면 비율이 실제로 흔들린다.

**오늘 분석에서 명확한 제거 후보는 찾지 못했다.**
행동 메커닉이 7개뿐이라 뺄 것이 애초에 적다. `추론`

## 10. 기획자로서 배울 점

### ① 정보를 공짜로 주면 부족한 것이 하나로 줄어든다

이 게임의 출발점이다.

```
정보를 감춘다 → 부족한 것이 정보 + 행동 → 대비와 확률의 문제
정보를 준다   → 부족한 것이 행동뿐     → 조합과 순서의 문제
```

**자원을 하나로 줄이면 플레이어의 사고가 그 하나에 모인다.** `추론`

[Alien: Isolation](./AlienIsolation.md)과 정확히 반대 방향이다.
그쪽은 정보를 조각으로 줘서 **불안**을 만들었고, 이쪽은 전부 줘서 **계산**을 만든다.

> 정보량은 난이도 손잡이가 아니라 **장르 손잡이**다.

### ② 행동이 사는 것을 데미지가 아닌 다른 것으로 정할 수 있다

이 게임에서 행동은 적의 체력이 아니라 **예고된 결과**를 산다. `추론`

| | 행동이 바꾸는 것 |
|---|---|
| 일반적인 전투 게임 | 현재 상태 (체력) |
| **Into the Breach** | **아직 오지 않은 결과** |

그래서 `죽이지 못한 공격`도 성공이 된다.
**무엇을 성공으로 칠 것인가를 다시 정하면 플레이의 폭이 넓어진다.**

### ③ 난이도는 강함이 아니라 문제 수 대 행동 수의 비율이다

이번 분석에서 가장 재사용성이 높은 도구다.

```
문제가 너무 적다 → 고민할 이유가 없다
비율이 맞는다   → 비교하고 순서를 따진다
문제가 너무 많다 → 해답이 없어진다
```

**적의 체력을 올리는 것은 이 비율을 바꾸지 않는다.** `추론`
난이도를 조절하려면 위협의 **개수**나 플레이어의 **행동 수**를 건드려야 한다.

### ④ 유닛 수는 설정이 아니라 설계 변수다

메카 3대가 그렇다.

| | |
|---|---|
| 2대 | 해답이 없는 판이 생긴다 |
| 3대 | 해답은 있되 쉽게 안 보인다 |
| 4대 | 여유가 생겨 고민이 줄어든다 |

**`몇 명인가`를 세계관으로 정하면, 그 결정이 난이도까지 정해 버린다.** `추론`

### ⑤ 정보를 공개하면 책임이 생긴다

실패했을 때 플레이어가 무엇을 탓하는지가 달라진다. `추론`

```
몰랐다 → 운이 나빴다 → 게임 탓
알았다 → 막을 방법을 못 찾았다 → 내 탓
```

**정보 공개는 친절이 아니라 책임의 이전이다.**

[Failure Design](../MechanicStudy/FailureDesign.md)의 `원인 가독성`을 극한까지 올린 형태이며,
가독성이 100%면 **실패가 전부 학습이 된다.** `추론`

### ⑥ 성장이 양이 아니라 종류를 늘리면 비율이 유지된다

8번에서 정리한 것이다.

```
행동 수를 늘린다   → 비율이 무너진다 → 퍼즐이 쉬워진다
해결 방법을 바꾼다 → 비율은 그대로   → 같은 문제가 다른 퍼즐이 된다
```

**퍼즐형 게임에 성장을 넣고 싶다면 강해지는 쪽이 아니라 달라지는 쪽으로 넣는다.** `추론`

### ⑦ 같은 `플레이어의 성장`이라도 종류가 다르다

[세키로](./Sekiro.md)와 나란히 놓으면 차이가 분명하다. `추론`

| 게임 | 플레이어가 만드는 것 | 요구하는 것 |
|---|---|---|
| 세키로 | **숙련된 대응** | 시간과 타이밍 |
| **Into the Breach** | **상황에 대한 해답** | 정보와 공간, 행동 순서 |

둘 다 `캐릭터가 아니라 플레이어가 강해지는 게임`이지만, 강해지는 부위가 다르다.
앞은 **손**이 늘고, 뒤는 **판단**이 는다.

> `플레이어가 성장한다`고 적을 때는 **무엇이 성장하는지**까지 적어야 한다.
