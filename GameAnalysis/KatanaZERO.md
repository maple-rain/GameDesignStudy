# Katana ZERO

근거 표기는 [Shadow Tactics](./ShadowTactics.md)에서 정한 3단계를 그대로 쓴다.

| 표기 | 근거 | 3단계 중 |
|---|---|---|
| `관찰` | 게임에서 실제로 일어나는 것 | ① 관찰 |
| `추론` | 왜 그렇게 만들었을지에 대한 가설. 확정된 결론이 아니다 | ② 설계적 추론 |
| `자료` | 개발자 발언이나 공식 자료로 확인된 것 | ③ 외부 근거 |

이 문서에도 `자료` 표기는 없다. 개발자 인터뷰나 공식 자료를 확인하지 않았다.

## 2. Core Experience

> 한 방을 놓고 `관찰 → 계획 → 실행 → 실패 → 수정`을 반복하며, **자기 나름의 해법을 만들어 실행하는 것** `추론`

적을 쓰러뜨리는 것은 목표일 뿐이고, 평가받는 것은 **어떤 방법으로 쓰러뜨렸는가**다.

같은 방에서도 정면 공격 · 회피 · 불릿 타임 · 총알 반사 · 오브젝트 활용 · 조합이 전부 성립한다. `관찰`

**따라서 이 게임의 전투는 문제 풀이의 형식을 갖는다.** `추론`

| | 퍼즐 게임 | Katana ZERO |
|---|---|---|
| 구조 | 문제 발견 → 해결 방법 탐색 → 실행 → 실패 / 성공 | 관찰 → 계획 → 실행 → 실패 → 수정 |
| 차이 | 생각하는 동안 세계가 멈춘다 | **생각하는 동안에도 시간이 흐른다** `관찰` |

## 4. 핵심 메커닉 분석

### 행동 메커닉 `관찰`

칼 · 구르기 · 불릿 타임 · 투척 · 환경 오브젝트 사용 · 무기 사용 · 총알 반사

### 시스템 메커닉 `관찰`

| 시스템 | 역할 |
|---|---|
| 즉사 판정 | 한 번의 피격으로 시도가 종료된다 |
| 즉시 재시작 | 실패와 다음 시도 사이의 간격을 없앤다 |
| 스테이지 제한 시간 | 고민과 대기를 억제한다 |

| 대화 선택지 | 태도 · 반응 · 연출 · 일부 인물의 생사를 바꾼다 |

### 메커닉 언어화 — 즉사 + 즉시 재시작

| 단계 | 내용 |
|---|---|
| 행동 | 계획한 순서대로 방에 진입해 실행한다 |
| 규칙 | 한 대라도 맞으면 즉시 사망하고, 곧바로 방 처음으로 돌아간다 `관찰` |
| 결과 | 잃는 것이 없으므로 **실패가 곧 그 방에 대한 정보**가 된다 `추론` |
| 감정 | 처벌받았다는 느낌보다 "이제 알았다"는 감각이 앞선다 `추론` |

**즉사만 보면 난이도 장치로 읽히지만, 재시작 지연이 0에 가깝기 때문에 실제 역할이 뒤집힌다.** `추론`

이것은 [Failure Design](../MechanicStudy/FailureDesign.md)에서 정리한 축으로 그대로 설명된다.

| 축 | Katana ZERO |
|---|---|
| 실패 비용 | 없음 (시간만) |
| 원인 가독성 | 매우 높음 — 무엇에 맞았는지가 즉시 보인다 `관찰` |
| 실패의 산출물 | 그 방의 적 배치와 타이밍에 대한 정보 |
| 재시작 지연 | 거의 없음 |

> **난이도를 정하는 것은 즉사가 아니라 재시작 지연이다.** `추론`
> 같은 즉사 판정이라도 재시작이 10초 걸리면 처벌이 되고, 1초면 학습이 된다.

### 메커닉 언어화 — 스테이지 제한 시간

| 단계 | 내용 |
|---|---|
| 행동 | 방에 들어가 다음 수를 판단한다 |
| 규칙 | 스테이지 전체에 제한 시간이 걸려 있다 `관찰` |
| 결과 | 멈춰서 관찰하거나 적을 기다리는 전략이 성립하지 않는다 `추론` |
| 감정 | 계속 앞으로 나가게 된다 `추론` |

표면적으로는 클리어 조건이지만, **실제 기능은 플레이어의 행동 방향을 정하는 것이다.** `추론`

## 5. 핵심 자원 (Core Resource)

### 1차 자원 — 한 번의 시도 안에서 쓸 수 있는 시간 `추론`

체력은 자원이 아니다. 즉사이기 때문에 **있거나 없거나** 둘뿐이다. `관찰`
그래서 이 게임에서 관리 대상이 되는 것은 시간이다.

그런데 시간을 다루는 시스템이 **서로 반대 방향으로 두 개** 걸려 있다. `관찰`

| 시스템 | 시간에 대해 하는 일 |
|---|---|
| 불릿 타임 | 판단할 시간을 **산다** |
| 스테이지 제한 시간 | 판단할 시간을 **뺏는다** |

```
불릿 타임을 오래 쓴다 → 한 방을 정확하게 푼다 → 전체 시간이 줄어든다
불릿 타임을 아낀다   → 전체 시간에 여유가 생긴다 → 한 방에서 실수할 확률이 오른다
```

**두 자원이 서로를 잡아먹는다.** `추론`
[Papers, Please](./PaperPlease.md)에서 본 구조와 같은 형태이며, 대상만 `생계와 양심`에서 `정확도와 속도`로 바뀌었다.

### 축적 자원 — 그 방에 대한 정보 `추론`

시도 사이에 남는 것은 이것뿐이다.

```
죽는다 → 위치도 시간도 되돌아간다 → 그런데 무엇에 죽었는지는 남는다
```

[Outer Wilds](./OuterWilds.md)의 `소모 자원과 축적 자원의 분리`가 훨씬 짧은 주기로 작동하는 형태다. `추론`
그쪽은 한 루프가 22분이고, 이쪽은 한 방이 몇 초다.

**주기가 짧을수록 축적이 지식이 아니라 손의 기억에 가까워진다.** `추론`

### 근거의 범위

| 항목 | 근거 |
|---|---|
| 대부분의 공격이 한 대에 죽고, 재시작이 즉시 이루어진다 | `관찰` |
| 모든 스테이지에 제한 시간이 있다 | `관찰` |
| 불릿 타임과 제한 시간이 하나의 자원을 두고 반대로 작동한다 | `추론` — 두 시스템의 기능에서 역산했다 |
| 불릿 타임 게이지의 회복 속도, 제한 시간의 실제 여유 폭 | **미검증** |

> **검증 방법**: 같은 스테이지를 불릿 타임을 최대한 쓴 경우와 거의 쓰지 않은 경우로 나눠 클리어하고, 남은 제한 시간을 비교하면 두 자원이 실제로 교환 관계인지 판정할 수 있다.

## 6. 플레이 루프

```
관찰        방에 들어가기 전에 적과 지형을 본다
  ↓
계획        어떤 수단을 어떤 순서로 쓸지 정한다
  ↓
실행        제한 시간에 밀려 곧바로 시도한다
  ↓
실패        읽지 못한 적이나 타이밍이 드러난다
  ↓
수정        즉시 재시작하고 그 부분만 고친다
  ↓
성공        방 하나가 하나의 해법으로 닫힌다
```

이 루프의 특징은 **되돌아가는 지점이 조작이 아니라 계획이라는 것**이다. `추론`

| 게임 | 실패 후 다시 하는 것 |
|---|---|
| [Celeste](./Celeste.md) | 같은 조작을 더 정확하게 |
| [Shadow Tactics](./ShadowTactics.md) | 같은 상황을 다른 계획으로 |
| **Katana ZERO** | **계획을 고치고, 그것을 정확하게 실행하는 것까지** |

Celeste는 답이 정해져 있고 손이 따라가는 게임이고, Shadow Tactics는 손보다 계획이 전부인 게임이다.
Katana ZERO는 **둘 다 요구한다.** `추론`
그래서 액션이면서 퍼즐이라는 인상이 생긴다.

## 7. Problem Chaining

```
1차   이 적을 어떻게 처리하는가
  ↓
2차   처리하는 동안 다른 적의 사선에 들어가지 않는가
  ↓
3차   그 순서를 제한 시간 안에 끝낼 수 있는가
  ↓
4차   불릿 타임을 여기서 쓰면 다음 방에서 부족하지 않은가
  ↓
5차   이 해법을 실수 없이 재현할 수 있는가
```

문제가 `처리 → 배치 → 시간 → 배분 → 재현`으로 옮겨간다.

주목할 점은 **4차에서 문제의 범위가 방 하나를 넘어간다**는 것이다. `추론`
방 단위로 최적인 해법이 스테이지 단위에서는 손해가 될 수 있고, 그때부터 플레이어는 방이 아니라 스테이지를 하나의 문제로 보게 된다.

## 8. 제거 / 변경 분석

이번 분석에서는 **제거 후보를 하나 떠올렸다가 판정을 보류했다.**

특정 캐릭터(Coffin Head)를 없어도 되는 요소라고 생각했는데, 그 판단의 근거를 되짚어 보니 기능 분석이 아니라 **취향**이었다.

### 그래서 절차를 먼저 만들었다

```
1. 이 요소가 게임의 핵심 경험에 어떤 기능을 하는가?
2. 기능이 없다  → 제거 후보
3. 게임플레이 기능은 없다 → 여기서 멈추지 않는다
4. 세계관 · 유머 · 분위기 · 캐릭터성 · 메타적 재미를 맡고 있는가?
5. 맡고 있다면 제거 후보가 아니다
```

3번이 이번에 추가된 단계다.

> **`게임플레이 기능이 없다`와 `기능이 없다`는 다르다.** `추론`

이 구분은 [INSIDE](./INSIDE.md)에서 정리한 `플레이 필수 / 경험 강화` 구분과 같은 곳을 가리킨다.
INSIDE의 병아리는 플레이에 필수가 아니지만 몰입을 만들었다. 같은 기준을 여기에 적용하면 취향만으로는 판정할 수 없다.

| 항목 | 상태 |
|---|---|
| 이 요소를 좋아하지 않는다 | `관찰` — 다만 이것은 나에 대한 사실이지 게임에 대한 사실이 아니다 |
| 이 요소가 핵심 경험에 어떤 기능을 하는가 | **미검증** |

> **검증 방법**: 그 요소가 등장하는 구간을 통째로 들어냈다고 가정하고, 사라지는 것을 적어 본다. 아무것도 적히지 않으면 제거 후보가 맞고, 분위기나 캐릭터의 인상이 적힌다면 기능이 있는 것이다.

**판정하지 못한 것을 판정한 것처럼 적지 않는다.** 이번 항목의 결론은 `보류`다.

## 9. 디자이너 의도 추론

**① 관찰**

- 즉사와 무제한 재시도가 함께 걸려 있다 `관찰`
- 모든 스테이지에 제한 시간이 있다 `관찰`
- 해결 수단은 여러 개인데 무기 교체에는 제약이 있다 `관찰`
- 대화 선택지가 서사의 큰 흐름을 바꾸지 않는데도 선택 행동 자체가 연출로 처리된다 `관찰`

**② 설계적 추론**

> 플레이어가 정답을 받아 실행하는 것이 아니라, **자기 해법을 만들어 실행하게 하는 것.** `추론`

세 설계가 같은 방향을 가리킨다.

| 설계 | 그 결과 |
|---|---|
| 즉사 + 즉시 재시작 | 실패가 처벌이 아니라 정보가 되어, 시도 자체가 싸진다 |
| 제한 시간 | 안전하게 기다리는 해법이 지워지고 능동적인 해법만 남는다 |
| 수단은 많고 교체에는 제약 | 질문이 `무엇을 쓸까`에서 `가진 것을 어떻게 조합할까`로 바뀐다 |

**셋을 합치면 "많이 시도하되, 매번 다르게 시도하라"는 하나의 요구가 된다.** `추론`

**③ 외부 근거**

없다. 따라서 ②는 여기서 멈춘다.

## 10. 기획자로서 배울 점

### ① 액션의 퍼즐화

이번 분석에서 새로 만든 개념이다.

> 주어진 적 · 지형 · 능력 · 제약을 이용해 **플레이어가 해결 방법을 설계하도록** 만드는 것.

`관찰 → 계획 → 실행 → 실패 → 수정` 구조가 성립하면, 장르가 액션이어도 플레이어는 전투를 **문제**로 받아들인다. `추론`

앞으로 액션 게임을 분석할 때 쓸 수 있는 기준이다.

- 이 게임의 전투에 `계획` 단계가 있는가
- 실패했을 때 고칠 대상이 조작인가 계획인가
- 같은 상황에 성립하는 해법이 몇 가지인가

### ② 즉사는 난이도가 아니라 회전 속도다

즉사 판정 하나만 보고 난이도를 판단하면 틀린다.

```
즉사 + 긴 재시작    → 처벌
즉사 + 즉시 재시작  → 학습
```

**난이도 손잡이는 피격 판정이 아니라 재시작 지연 쪽에 있다.** `추론`
[Failure Design](../MechanicStudy/FailureDesign.md)의 `재시작 지연이 곧 난이도다`가 여기서 다시 확인된다.

### ③ 제약이 조합을 만든다

수단을 많이 주면 플레이어는 가장 좋은 것 하나만 쓴다.
교체에 제약을 걸면 질문이 바뀐다. `추론`

| 제약이 없을 때 | 제약이 있을 때 |
|---|---|
| 무엇이 제일 센가 | 지금 가진 것으로 어떻게 푸는가 |

**선택지의 개수보다 선택지의 가용 조건이 조합을 만든다.**
[Hades](./Hades.md)의 `선택지의 개수 ≠ 선택의 다양성`과 같은 지점이다.

### ④ 규칙 하나가 행동의 방향을 정한다

제한 시간은 클리어 조건처럼 보이지만 실제로는 플레이 스타일을 지정하는 장치다.

> 시스템을 추가할 때는 `무엇을 제한하는가`가 아니라 **`어떤 플레이를 지우는가`**를 본다. `추론`

제한 시간이 지운 것은 시간이 아니라 **기다리는 플레이**다.

### ⑤ 선택의 가치는 분기량으로 재지 않는다

[Disco Elysium](./DiscoElysium.md)에서 얻은 결론이 다시 확인됐다.

Katana ZERO의 선택지는 큰 줄기를 바꾸지 않지만, 태도 · 진행 · 반응 · 연출 · 일부 인물의 생사를 바꾼다. `관찰`
특히 **상대의 말을 끊는 행동 자체를 게임이 받아준다.** `관찰`

> 분기를 만들지 않아도, 플레이어의 입력을 게임이 알아봤다는 사실만으로 선택이 살아난다. `추론`

다만 한계도 같이 적어 둔다.
**변화의 폭이 충분하지 않으면 플레이어는 결국 선택을 무의미하다고 느낀다.** 이것은 분기량의 문제가 아니라 **체감되는 반응량**의 문제다. `추론`

### ⑥ 취향은 제거 판정의 근거가 아니다

가장 크게 남은 것이다.

`싫다`는 나에 대한 사실이고, `기능이 없다`는 게임에 대한 사실이다.
둘을 구분하지 않으면 분석이 감상으로 내려간다.
