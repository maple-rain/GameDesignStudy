# Sekiro: Shadows Die Twice

근거 표기는 [Shadow Tactics](./ShadowTactics.md)에서 정한 3단계를 쓴다.

| 표기 | 근거 | 3단계 중 |
|---|---|---|
| `관찰` | 게임에서 실제로 일어나는 것 | ① 관찰 |
| `추론` | 왜 그렇게 만들었을지에 대한 가설. 확정된 결론이 아니다 | ② 설계적 추론 |
| `자료` | 개발자 발언이나 공식 자료로 확인된 것 | ③ 외부 근거 |

이 문서에도 `자료` 표기는 없다.

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 장르 | 액션 어드벤처 |
| 전투의 축 | 체력과 별개로 **체간(Posture)**이 존재하며 양쪽 다 가진다 `관찰` |
| 승리 조건 | 체력 소진이 아니라 **체간을 무너뜨려 인살** `관찰` |
| 대응 | 적의 행동마다 정해진 대응이 다르다 (튕겨내기 · 간파 · 점프 · 회피) `관찰` |
| 성장 | 캐릭터 성장과 플레이어 숙련이 함께 간다 `관찰` |
| 죽음 | 부활이 가능하고, 완전 사망 시 돈과 경험치를 일부 잃는다 `관찰` |

두 번째와 세 번째가 이 게임의 전투를 결정한다. `추론`

**체력을 깎는 게임이 아니라 자세를 무너뜨리는 게임이며, 무너뜨리는 방법이 대응의 정확도다.**


**보스를 넘은 것은 캐릭터가 강해져서가 아니라 플레이어가 달라졌기 때문이다.** `추론`

## 3. 재미 요소 분석

| 재미 요소 | 이유 | 감정 |
|---|---|---|
| 맞부딪히는 감각 | 공격을 피하는 것이 아니라 받아내며 밀어낸다 `관찰` | 물러서지 않아도 된다 |
| 대응이 맞았을 때 | 행동마다 정해진 답이 있고 그것이 통한다 `관찰` | 알아봤다 |
| 나아지는 것이 보임 | 어제 못 넘긴 패턴을 오늘 넘긴다 `관찰` | 이번엔 잡겠다 |
| 도구로 문제를 푸는 재미 | 적의 특성에 맞는 의수 도구가 있다 `관찰` | 이 적은 이걸로 |
| 인살의 마무리 | 체간을 무너뜨린 결과가 한 번에 정리된다 `관찰` | 끝냈다 |

첫 줄이 이 게임의 정체성이다. `추론`

**회피형 전투에서 물러서는 것이 정답이라면, 여기서는 자리를 지키는 것이 정답이다.**

## 4. 핵심 메커닉 분석

### 행동 메커닉 `관찰`

이동 · 공격 · 방어 · 튕겨내기 · 간파 · 점프 · 회피 / 대시 ·
의수 도구 사용 · 암살 · 갈고리 이동

**각 행동이 특정 적 행동에 대응한다는 점이 이 목록의 성격이다.** `관찰`

| 적의 행동 | 대응 |
|---|---|
| 일반 공격 | 튕겨내기 |
| 찌르기 | 간파 |
| 특정 위험 공격 | 점프 |
| 상황에 따라 | 회피 · 이동 |
| 특정 적의 약점 | 의수 도구 |

### 시스템 메커닉 `관찰`

체력 · 체간 · 튕겨내기 판정 · 가드 연타 시 판정 축소 · 자세 붕괴와 인살 ·
의수 도구 · 부활 · 사망 시 손실과 용해 · 잠입과 암살

### 메커닉 언어화 — 체간

| 단계 | 내용 |
|---|---|
| 행동 | 공격을 받거나 막거나 튕겨낸다 |
| 규칙 | 맞으면 체력과 체간이 깎이고, 막아도 체간이 깎이며, 튕겨내면 손실이 줄고 **상대의 체간도 깎인다** `관찰` |
| 결과 | **방어가 안전한 선택이 아니게 된다** `추론` |
| 감정 | 버티고만 있으면 진다 `추론` |

이것이 이 게임의 핵심 설계다. `추론`

```
일반적인 액션 게임 — 방어는 비용이 없다 → 기다리는 것이 안전하다
세키로            — 방어에도 값이 붙는다 → 기다리는 것이 지는 길이다
```

**방어에 값을 붙이면 소극적인 플레이가 전략에서 빠진다.** `추론`

### 메커닉 언어화 — 튕겨내기

| 단계 | 내용 |
|---|---|
| 행동 | 공격이 닿는 순간에 맞춰 방어를 입력한다 |
| 규칙 | 성공하면 자신의 체간 손실이 줄고 상대의 체간이 깎인다 `관찰` |
| 결과 | **하나의 입력이 두 게이지를 동시에 움직인다** `추론` |
| 감정 | 막은 게 아니라 밀어냈다 `추론` |

일반적인 전투는 공격 구간과 방어 구간이 나뉘어 있다.
여기서는 **같은 입력이 방어이면서 공격이므로 두 구간이 겹친다.** `추론`

그래서 전투의 모양이 이렇게 바뀐다.

| | 흐름 |
|---|---|
| 회피형 전투 | 공격 → 피함 → 빈틈에 공격 |
| **세키로** | **공격 → 받아냄 → 튕겨냄 → 체간 압박 → 자세 붕괴 → 인살** |

### 메커닉 언어화 — 가드 연타 시 판정 축소

| 단계 | 내용 |
|---|---|
| 행동 | 가드 버튼을 연속 입력한다 |
| 규칙 | 연타할수록 튕겨내기 판정이 짧아진다 `관찰` |
| 결과 | **연타가 정확한 입력보다 불리해진다** `관찰` |
| 감정 | 그냥 누르면 안 되는구나 `추론` |

**난이도 장치가 아니라 습관 교정 장치다.** `추론`

```
연타를 막지 않는다 → 통하는 동안 계속 연타한다 → 보는 법을 배우지 않는다
연타에 값을 매긴다 → 정확한 입력이 유리해진다 → 보고 반응하게 된다
```

> 원하는 플레이가 있다면, 그것을 요구하기 전에 **원하지 않는 플레이의 효율을 낮추는 방법**이 있다.

## 5. 핵심 자원 (Core Resource)

### 1차 자원 — 체간, 즉 전투의 주도권 `추론`

이 게임에서 다투는 것은 체력이 아니다. **누가 먼저 자세를 잃는가**다.

체간이 특이한 이유는 **양쪽이 같은 종류의 자원을 두고 서로 밀어낸다**는 점이다. `관찰`

| 행동 | 내 체간 | 상대 체간 |
|---|---|---|
| 그대로 맞는다 | 크게 깎인다 (+체력) | — |
| 그냥 막는다 | 깎인다 | — |
| **튕겨낸다** | **덜 깎인다** | **깎인다** |
| 공격한다 | — | 깎인다 |

**세 번째 줄만 두 칸을 동시에 움직인다.** `추론`
그래서 튕겨내기가 선택지 중 하나가 아니라 **이 전투의 기본형**이 된다.

### 이 자원의 성격 — 줄다리기

지금까지 분석한 자원들과 형태가 다르다. `추론`

| 게임 | 자원의 형태 |
|---|---|
| [Katana ZERO](./KatanaZERO.md) | 내가 쓰면 줄어든다 |
| [Alien: Isolation](./AlienIsolation.md) | 내 상태가 깎인다 (잔량이 안 보임) |
| **Sekiro** | **양쪽이 같은 자원을 두고 서로 민다** |

앞의 것들은 **관리**의 대상이고, 이것은 **경합**의 대상이다.
그래서 이 게임에서는 자원을 아끼는 것이 답이 되지 않는다. 아끼면 밀린다. `추론`

### 2차 자원 — 부활 `관찰`

죽어도 일정 시간 안에 부활할 수 있다.
**한 번의 실수를 즉시 패배로 만들지 않으면서, 무한하지도 않은 완충재다.** `추론`

### 축적 자원 — 적의 패턴에 대한 지식과 손의 숙련 `관찰`

죽어도 남고, 회차를 넘어서도 남는다.

```
실패 → 패턴 확인 → 대응법 발견 → 재도전 → 숙련 → 성공
```

**이 게임에서 실제로 성장하는 것은 여기다.** `추론`

### 근거의 범위

| 항목 | 근거 |
|---|---|
| 체간이 체력과 별도로 존재하고 양쪽 다 가진다 | `관찰` |
| 방어는 체간을 깎고, 튕겨내기는 손실을 줄이며 상대 체간을 깎는다 | `관찰` |
| 가드 연타 시 튕겨내기 판정이 짧아진다 | `관찰` |
| `체간은 관리가 아니라 경합의 자원`이라는 해석 | `추론` — 같은 자원을 양쪽이 밀어낸다는 점에서 역산했다 |
| 체간 회복 속도, 튕겨내기 판정 프레임, 연타 시 축소 폭 | **미검증** |

> **검증 방법**: 같은 보스를 상대로 한 번은 방어만, 한 번은 튕겨내기 중심으로 진행해 자세 붕괴까지 걸린 시간을 비교하면 두 행동의 값 차이를 잴 수 있다.

## 6. 플레이 루프

**이 게임의 루프는 크기가 다른 두 개이고, 안쪽이 실패해야 바깥쪽이 돈다.** `추론`

```
[전투 안]                          [보스 재도전]
적 관찰                            실패
  ↓                                  ↓
패턴 파악                          패턴 확인
  ↓                                  ↓
대응 선택                          대응법 발견
  ↓                                  ↓
공격 · 튕겨내기                     재도전
  ↓                                  ↓
체간 압박 → 자세 붕괴 → 인살        숙련 → 성공
```

바깥 루프가 이 게임의 실질적인 진행이다. `추론`

**죽는 것이 루프를 돌리는 입력이므로, 반복적인 사망이 콘텐츠의 일부가 된다.**

## 7. Problem Chaining

이 게임의 체인은 **초 단위로 돌아간다.** `추론`

```
적이 움직인다
  ↓
이게 어떤 공격인지 판별한다 (일반? 찌르기? 위험 공격?)
  ↓
판별에 맞는 입력을 낸다
  ↓
맞으면 상대 체간이 깎이고 주도권이 넘어온다
  ↓
틀리면 내 체간이 깎이고 다음 공격이 이어진다
  ↓
다시 판별한다
```

**틀린 판별의 대가가 즉시 다음 문제로 이어진다는 점이 특징이다.** `추론`
공격이 연계되기 때문에 한 번 밀리면 판별할 시간이 더 줄어든다.

|---|---|
| [Shadow Tactics](./ShadowTactics.md) | 미션 하나 |
| [DEATHLOOP](./Deathloop.md) | 하루 |
| **Sekiro** | **적의 공격 하나** |

## 8. 제거 / 변경 분석

### 용해 — 죽음의 두 역할이 충돌한다

이 게임에서 죽음은 두 가지 일을 한다. `관찰`

| 죽음의 역할 | 근거 |
|---|---|
| 손실을 만든다 | 돈과 경험치를 일부 잃는다 |
| **학습 시간을 준다** | 반복적인 죽음이 패턴을 익히게 한다 |

그런데 여기에 **용해**가 붙는다.
반복적인 사망이 NPC에게 상태 이상을 일으켜 다른 시스템에까지 영향을 준다. `관찰`

**두 방향이 어긋난다.** `추론`

```
이 게임의 학습 구조 — 많이 죽어야 배운다
용해              — 많이 죽으면 게임 밖의 것을 잃는다
```

[Sleeping Dogs](./SleepingDogs.md)의 5개 층위로 보면 자리가 애매하다.

| 층위 | 해당 여부 |
|---|---|
| 핵심 게임플레이 | 아니다 — 전투 판단에 개입하지 않는다 |
| 성장 시스템 | 부분적으로 |
| 공간 / 세계 경험 | **그렇다** — 죽음이 세계에 흔적을 남긴다 |
| 장식 / 분위기 | 그렇다 |

**세 번째 칸이 이 요소가 살아 있는 이유다.** `추론`
죽음이 아무 흔적도 남기지 않으면 세계가 플레이어의 실패에 반응하지 않게 된다.

다만 [BioShock Infinite](./BioShockInfinite.md)의 중심축 검사를 대면 긴장이 남는다.
이 게임의 중심축이 `실패를 통한 학습`이라면, **학습에 필요한 행동에 추가 벌을 붙이는 것은 축과 어긋난다.** `추론`

### 판정을 보류한다

| 항목 | 상태 |
|---|---|
| 용해의 실제 페널티가 학습을 위축시킬 만큼 큰가 | **미검증** |

> **검증 방법**: 용해를 방치한 상태로 한 보스를 계속 도전해 보고, 실제로 진행이 막히는지 아니면 대사와 이벤트 일부만 달라지는지 확인한다. 후자라면 위축 효과는 심리적인 쪽이고, 그렇다면 문제는 페널티의 크기가 아니라 **표시 방식**이다.

**두 시스템이 반대 방향을 본다는 점만 기록하고, 제거 여부는 판정하지 않는다.**

### 잠입은 얕은 것이 아니라 배치다

이 게임은 잠입과 암살, 갈고리 이동, 엿듣기를 제공하지만 **잠입만으로 모든 상황을 해결하도록 설계되지 않았다.** `관찰`

이것을 `잠입이 얕다`로 읽으면 판정이 틀린다. `추론`
필드의 잠입은 **보스전이라는 본론에 들어가기 전의 자원 정리와 정보 수집** 역할이며,
[Shadow Tactics](./ShadowTactics.md)처럼 잠입이 본론인 게임과는 자리가 다르다.

## 9. 디자이너 의도 추론

**① 관찰**

- 체간을 체력과 분리하고 양쪽 다 갖게 했다 `관찰`
- 방어에도 체간 비용을 붙였다 `관찰`
- 적의 행동마다 다른 대응을 지정했다 `관찰`
- 가드 연타에 불이익을 붙였다 `관찰`
- 죽어도 패턴 지식이 남는다 `관찰`

**② 설계적 추론**

> 공격력으로 이기게 하는 것이 아니라, **적의 행동에 맞는 정확한 대응을 수행하는 능력 자체**를 핵심 경험으로 만드는 것. `추론`

다섯 관찰이 하나의 요구로 모인다.

| 설계 | 그 결과 |
|---|---|
| 방어에 값을 붙인다 | 버티기가 전략에서 빠진다 |
| 대응을 1:1로 지정한다 | 암기가 아니라 판별의 문제가 된다 |
| 연타에 불이익을 준다 | 보고 반응하는 습관이 생긴다 |
| 지식이 남는다 | 실패가 학습이 된다 |

**즉 이 게임이 설계한 것은 난이도가 아니라 연습이다.** `추론`

**③ 외부 근거**

없다. 따라서 ②는 여기서 멈춘다.

## 10. 기획자로서 배울 점

### ① 방어에 값을 붙이면 소극적 플레이가 사라진다

대부분의 액션 게임에서 방어는 비용이 낮아서, 막고 기다리는 것이 안전한 선택이 된다. `추론`

체간은 그 선택에 값을 매긴다.

> **막는 것이 공짜가 아니면, 기다리는 것은 지는 길이 된다.**

플레이어를 앞으로 나오게 하고 싶다면 공격에 보상을 붙이는 것보다 **방어에 비용을 붙이는 쪽**이 직접적이다. `추론`

### ② 하나의 입력이 두 게이지를 움직이면 공방이 하나가 된다

튕겨내기가 그렇다. 방어이면서 동시에 공격이다. `관찰`

```
입력이 나뉘어 있다 → 공격 구간과 방어 구간이 나뉜다 → 번갈아 한다
입력이 겹쳐 있다   → 두 구간이 겹친다 → 맞부딪히는 전투가 된다
```

**전투의 리듬은 애니메이션이 아니라 입력의 구조가 만든다.** `추론`

### ③ 원하지 않는 플레이의 효율을 낮춘다

가드 연타 판정 축소가 그 사례다.

| 방법 | 성격 |
|---|---|
| 원하는 플레이를 지시한다 | 튜토리얼 |
| 원하는 플레이에 보상을 준다 | 유도 |
| **원하지 않는 플레이의 효율을 낮춘다** | **습관 교정** |

세 번째는 플레이어가 스스로 바꾸게 만든다. `추론`
[Metal Gear Solid V](./MetalGearSolidV.md)의 `적이 반복 전술에 대응한다`와 같은 계열이며,
그쪽은 세계가 적응하고 이쪽은 **입력 판정이 반응한다.**

### ④ 대응을 1:1로 지정하면 암기가 판별이 된다

행동마다 답이 정해져 있다는 것은 자유도를 줄이는 것처럼 보인다. `추론`
하지만 그 결과 플레이어가 하는 일이 바뀐다.

| | 플레이어가 하는 일 |
|---|---|
| 모든 상황에 하나의 대응 | 그 하나를 얼마나 잘하는가 |
| **상황마다 다른 대응** | **지금이 어떤 상황인지 알아보는가** |

**후자에서는 실력이 손이 아니라 눈에서 나온다.** `추론`

### ⑤ 캐릭터 성장이 숙련을 대신하지 못하게 한다

이 게임에는 두 성장이 다 있지만 **서로를 대체하지 않는다.** `관찰`

```
캐릭터만 강해진다 → 패턴을 몰라도 넘어간다 → 배우지 않는다
숙련만 요구한다   → 막힌 사람이 나아갈 길이 없다
둘 다 두되 대체 불가 → 강해져도 배워야 하고, 배우면 훨씬 쉬워진다
```

[Monster Hunter: World](./MonsterHunterWorld.md)에서는 두 성장이 **서로를 보완**해 난이도 폭을 넓혔다. `추론`
세키로는 같은 두 축을 두되 **보완의 정도를 좁혀서** 학습을 필수로 만들었다.

**같은 재료로 다른 게임이 되는 지점이다.**

### ⑥ 죽음이 학습 시간이라면, 죽음에 붙이는 벌은 조심해야 한다

8번에서 정리한 긴장이다.

> 실패가 학습 경로인 게임에서 실패에 추가 비용을 붙이면, **학습을 억제할 수 있다.** `추론`

[Failure Design](../MechanicStudy/FailureDesign.md)의 축으로 보면 이 게임은 실패의 산출물이 큰 쪽에 있다.
그렇다면 실패 비용은 **낮게 유지하는 것이 축과 맞다.**

이때 답은 페널티를 없애는 것이 아니라 **그것이 학습을 막는지 아닌지를 재 보는 것**이다.
