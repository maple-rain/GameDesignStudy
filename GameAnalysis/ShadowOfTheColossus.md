# 완다와 거상 (Shadow of the Colossus)

> 분석 기록: [TIL - 자료만으로는 어디까지 분석할 수 있는가](../TIL/2026/08-12-ShadowOfTheColossus.md)
> **분석 기반의 한계**: 과거에 직접 플레이한 게임이지만 플레이 경험이 선명하게 남아 있지 않아, 문서 자료를 중심으로 분석했다. 플레이 영상으로 검증하지 않았다.

이 문서는 근거를 문장 단위로 구분해서 적는다.

| 표기 | 근거 |
|---|---|
| `확인` | 공략 · 위키 · 분석글에서 확인한 것 |
| `기억` | 본인의 플레이 기억. 선명한 부분과 흐릿한 부분을 함께 밝힌다 |
| `추론` | 위 둘을 근거로 세운 가설. 확정된 결론이 아니다 |

---

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 장르 | 액션 어드벤처 |
| 설정 | 죽은 소녀 모노를 되살리기 위해 완다가 금단의 땅에 들어간다 |
| 구조 | 신전에서 출발해 거상을 찾아 쓰러뜨리고 다시 신전으로 돌아온다 |
| 분량 | 거상 16체 |

일반적인 액션 게임의 `스테이지 → 보스방 → 보스` 구조가 없다.
거상을 찾아가는 과정과 거상을 쓰러뜨리는 과정, 두 가지만 반복된다.

## 2. Core Experience

> 거대한 존재를 하나의 문제로 받아들이고, 그 위에 직접 올라가 해결하는 것 `추론`

이 게임에서 **거상은 보스이면서 동시에 스테이지다.**

일반적인 보스전이 `패턴 관찰 → 회피 → 공격`이라면, 여기서는
`구조 파악 → 접근 방법 발견 → 등반 → 약점 발견 → 공격`이 된다.

보스와 레벨 디자인이 하나의 오브젝트에 합쳐져 있다. `추론`

## 3. 재미 요소 분석

| 재미 요소 | 이유 | 감정 |
|---|---|---|
| 거대한 존재와의 대면 | 크기와 위용이 플레이어의 규모를 압도한다 | 경외감과 두려움 |
| 올라갈 방법을 찾는 것 | `어떻게 공격하지`가 아니라 `어떻게 저 위에 올라가지`부터 묻게 된다 | 문제를 마주한 감각 |
| 신전에서 거상까지의 여정 | 넓은 땅을 가로질러 직접 찾아간다 | 모험과 고독 |
| 토벌 | 감당하기 어려운 크기의 존재를 자신의 힘으로 넘어선다 | 성취감 |

**첫 번째 질문이 `공격`이 아니라 `접근`이라는 점이 이 게임을 다른 액션 게임과 구분한다.** `추론`

## 4. 핵심 메커닉 분석

### 행동 메커닉 `확인`

| 행동 | 역할 |
|---|---|
| 이동 · 점프 | 기본 이동 |
| 공격 | 약점 타격 |
| 회피 | 거상의 공격과 진동 회피 |
| 매달리기 | 거상의 몸에 붙어 있는다 |
| 거상 등반 | 붙은 상태로 위로 이동한다 |
| 검을 이용한 거상 위치 탐색 | 다음 거상의 방향을 찾는다 |
| 활 사용 | 원거리 상호작용 |
| 아그로 탑승 및 이동 | 장거리 이동 |
| 아그로 호출 | 말을 부른다 |

### 시스템 메커닉 `확인`

```
거상 탐색 → 거상 위치 발견 → 거상별 기믹 해결 → 거상 등반
→ 약점 탐색 → 약점 공격 → 거상 토벌 → 신전 귀환
```

여기에 성장과 반복 요소가 붙는다 — 체력 및 악력 성장, 하드 모드, 타임어택.

### 거상은 개별 기믹이 아니라 기믹형 스테이지다 `추론`

처음에는 약점을 찾아 공격하는 것을 기믹으로 보았다.
그러나 약점 하나하나를 개별 기믹으로 보는 것보다,
**거상이라는 존재 자체가 하나의 기믹형 스테이지**라고 보는 편이 구조를 더 잘 설명한다.

거상의 몸 구조, 움직임, 주변 환경을 함께 읽어야 접근 경로가 나오기 때문이다.

> 이 판단은 영상으로 검증하지 않았다.
> **검증 방법**: 거상 한 체의 공략 영상에서 플레이어가 첫 접근까지 무엇을 관찰하는지 확인하면 판정할 수 있다.

### 메커닉 언어화 — 매달리기

| 단계 | 내용 |
|---|---|
| 행동 | 거상의 몸에 매달려 위로 이동한다 |
| 규칙 | 매달리기와 벽타기는 악력을 소모하며, 악력은 유한하다 `기억` |
| 결과 | 아무 지점에서나 무한정 붙어 있을 수 없으므로, 올라가기 **전에** 경로를 정해야 한다 `추론` |
| 감정 | 거대한 대상 앞에서 무력하게 매달리는 것이 아니라, 제한된 여력을 배분하는 판단이 된다 `추론` |

## 5. 핵심 자원 (Core Resource)

### 악력 — 거상에 붙어 있을 수 있는 여력

**매달리기와 벽타기를 성립시키는 수치이며, 사실상 이 게임의 유일한 핵심 자원이다.** `기억`

이 게임에서 플레이어가 항상 부족한 것은 공격력도 체력도 아니다.
**거상의 몸 위에 계속 붙어 있을 수 있는 여력**이다.

악력이 핵심 자원이면 이 게임의 구조가 한 줄로 이어진다. `추론`

```
악력이 유한하다 → 아무 데나 붙어 있을 수 없다 → 올라갈 경로를 먼저 정해야 한다
→ 거상의 구조와 움직임을 관찰해야 한다 → 거상이 HP 덩어리가 아니라 하나의 문제가 된다
```

즉 **거상을 거대한 문제로 만드는 것은 거상의 크기가 아니라, 플레이어 쪽의 자원 한계다.**

### 근거의 범위

| 항목 | 근거 |
|---|---|
| 악력이 매달리기와 벽타기를 가능하게 한다 | `기억` |
| 악력이 이 게임의 거의 유일한 핵심 자원이다 | `기억` — 본인 판단 |
| 악력이 존재하고 성장시킬 수 있다 | `확인` |
| 특정 지점에 도달하려면 악력이 필요하다 | `확인` |
| 악력이 실제 거상전에서 어떤 판단과 감정을 만드는가 | **미검증** |

마지막 항목이 이번 분석에서 채우지 못한 칸이다.
수치와 실제 운용 방식을 확인할 수 없어 억지로 추론하지 않았다.

> **검증 방법**: 등반 중 악력 게이지가 도는 구간과, 플레이어가 멈춰서 회복을 기다리는 구간이 영상에 있는지 확인하면 된다.

## 6. 플레이 루프

```
신전
  ↓
검으로 다음 거상의 방향을 찾는다
  ↓
아그로를 타고 넓은 땅을 가로지른다
  ↓
거상 발견 → 구조와 행동을 관찰한다
  ↓
올라갈 방법을 찾는다 → 접근
  ↓
등반 (악력 소모)
  ↓
약점 발견 → 공격
  ↓
토벌
  ↓
신전 귀환 → 다음 거상
```

**루프의 절반이 전투가 아니라 이동과 관찰이다.** 이 비율이 이 게임의 성격을 정한다. `추론`

## 7. Problem Chaining

```
1차   다음 거상은 어디에 있는가
2차   거상에게 어떻게 접근하는가
3차   어디로 올라갈 수 있는가
4차   올라간 뒤 어느 경로로 이동하는가
5차   약점은 어디인가
6차   거상이 움직이는 동안 어떻게 붙어 있는가
```

문제의 크기가 **땅 전체 → 거상 한 체 → 거상의 몸 위 한 지점**으로 좁아진다.
그리고 각 층의 답이 다음 층의 조건이 된다.

## 8. 제거 / 변경 분석

| 후보 | 제거하면 | 판정 |
|---|---|---|
| 넓은 필드 | 거상과 세계의 규모를 표현할 공간이 사라진다 | **제거 불가** |
| 아그로 | 이동수단이 아니라 모험과 고독을 전달하는 캐릭터다. 플레이 기억에 가장 강하게 남은 것도 `아그로!` 하고 말을 부르던 장면이었다 `기억` | **제거 불가** |
| 시네마틱 카메라 | 거상의 크기와 위용을 전달하는 연출 수단이 사라진다 | **제거 불가** |
| 반복 플레이에서 동일한 장거리 이동을 다시 수행하게 만드는 구조 | 초회차의 모험 경험은 유지하면서 반복 플레이의 시간 소모만 줄일 수 있다 | **의심 — 실제 후보** |

### 이동 시간은 필요성과 반복을 나눠서 봐야 한다

`이동 시간이 필요한가`와 `반복 플레이에서 같은 이동을 다시 시켜야 하는가`는 다른 질문이다.

```
초회차   신전 → 넓은 세계 → 거상 발견     모험과 탐험의 경험을 만든다
반복     신전 → 말 타기 → 이동 → 거상      같은 이동이 시간 소모로 바뀐다
```

**초회차의 경험을 구성하던 요소가 반복 플레이에서 비용으로 재평가된다.** `추론`
따라서 제거 대상은 아그로도 넓은 필드도 아니고 **반복 구조**다.

### 시네마틱 카메라는 카메라가 문제가 아니다

지금 기준으로는 권장되지 않는 방식이지만, 이 게임에서 카메라는 편의 기능이 아니라 **거상의 크기를 체감시키는 연출 장치**다.

> 문제는 시네마틱 카메라 자체가 아니라, **연출을 위한 카메라와 플레이어의 조작권이 충돌하는 상황**이다.

## 9. 디자이너 의도 추론

> 인간이 감당하기 어려울 정도로 거대한 존재와 마주하고, 그 존재를 이해하며 극복하는 과정에서 경외감과 성취감을 경험하게 하는 것. `추론`

근거는 **플레이어가 거상을 보고 처음 떠올리는 질문이 무엇인가**다.

거상이 단순한 HP 덩어리였다면 질문은 `어떻게 공격하지`가 된다.
그러나 이 게임은 직접 올라타야 하므로 질문이 `어떻게 저 위에 올라가지`로 바뀐다.

**공격 대상이 아니라 등반 대상으로 만든 순간, 거상은 적이 아니라 하나의 거대한 문제가 된다.** `추론`

## 10. 기획자로서 배울 점

### ① 보스와 스테이지와 퍼즐을 한 오브젝트에 합칠 수 있다

| 일반적인 구조 | 완다와 거상 |
|---|---|
| 스테이지 → 보스방 → 보스 | 거상 발견 → 거상 자체가 스테이지 → 약점 발견 → 토벌 |

세 가지를 따로 만들지 않고 하나에 겹쳐 놓으면, 플레이어가 보스를 **공략 대상이 아니라 지형으로** 읽게 된다.

### ② 대상을 거대하게 만드는 것은 대상의 크기가 아니라 플레이어의 한계다

크기만 키우면 큰 적이고, **플레이어 쪽 자원에 한계를 두면 큰 문제**가 된다.
악력이 그 역할을 한다. `추론`

### ③ 확인한 것과 추론한 것을 나눠서 적는다

이번 분석에서 가장 크게 얻은 것은 게임에 대한 결론이 아니라 **분석 기록의 방식**이다.

> 게임 시스템의 존재를 아는 것과, 그 시스템이 실제 플레이에서 어떤 경험을 만드는지 아는 것은 다르다.

악력은 존재를 확인했지만 그것이 만드는 판단과 감정은 확인하지 못했다.
이때 칸을 억지로 채우지 않고 **미검증으로 남기고 검증 방법을 적어두는 것**이 다음 분석으로 이어진다.

**모르는 것을 아는 척하지 않는 것도 분석 능력이다.**
