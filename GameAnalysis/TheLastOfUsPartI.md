## 5. 핵심 자원 (Core Resource)

### 이 게임은 통화가 두 개다 `추론`

한 전투를 넘기려면 무언가를 지불해야 하는데, 지불 수단이 두 종류다.

| 통화 | 성격 |
|---|---|
| **물자** (탄약 · 제작 재료 · 소모품) | 쓰면 줄어들고, 일부만 회수된다 `관찰` |
| **소음** | 쓰면 적이 늘어난다 `관찰` |

그리고 **수단마다 두 통화의 환율이 다르다.** `추론`

| 수단 | 물자 | 소음 | 대신 요구하는 것 |
|---|---|---|---|
| 암살 | 없음 | 없음 | 접근이라는 위험 |
| 활 | 낮음 (회수 가능) | 낮음 | 조준과 타이밍 |
| 총기 | 높음 (회수 불가) | **높음** | 없음 — 그래서 비싸다 |
| 투척물 (병 · 벽돌) | 낮음 | **일부러 크게** | 위치 선정 |

마지막 줄이 이 표에서 가장 흥미롭다. `추론`

> **소음은 대개 치르는 값이지만, 투척물은 소음을 일부러 만들어 적을 옮긴다.**
> 같은 통화가 어떤 수단에서는 비용이고 어떤 수단에서는 도구다.

### 그래서 질문이 바뀐다

```
자원이 넉넉하다   → "죽일 수 있는가"
자원이 부족하다   → "이 방법으로 죽여도 되는가"
```

**자원을 조이면 전투가 실행의 문제에서 판단의 문제로 옮겨간다.** `추론`

여기에 적 종류별 드랍 차이가 겹친다. `관찰`
인간은 일부 자원을 주고 클리커는 거의 주지 않으므로,
**전투의 수지가 미리 계산되지 않는다.** 그래서 판단이 더 무거워진다. `추론`

### 시야가 한 전투를 넘어간다

플레이어가 계산하는 범위는 지금 이 전투가 아니다. `관찰`

```
여기서 탄약을 쓴다 → 다음 구간에서 쓸 것이 없다
→ 그래서 지금 불편해도 조용한 방법을 고른다
```

[Dishonored](./Dishonored.md)의 혼돈과 같은 구조다. `추론`
값이 이 장면이 아니라 **다음 장면에서 청구된다.**
다만 그쪽은 세계의 상태로 청구되고, 이쪽은 **내 주머니**로 청구된다.

### 축적 자원 — 그 공간에 대한 정보 `관찰`

적 배치가 고정되어 있으므로 반복하면 남는 것이 있다.

```
저 적은 저쪽으로 움직인다
저곳에서 공격하면 위험하다
여기서는 벽돌을 쓸 수 있다
```

**배치를 고정했기 때문에 학습이 자산이 된다.** `추론`
무작위 배치였다면 반복의 산출물이 남지 않는다.
[Hitman](./Hitman.md)에서 정리한 `예측 가능성은 계획의 전제조건이다`가 여기서도 그대로 작동한다.

### 근거의 범위

| 항목 | 근거 |
|---|---|
| 자원이 넉넉하게 지급되지 않는다 | `관찰` |
| 무기마다 소음이 다르고 적이 소리에 반응한다 | `관찰` |
| 일부 자원만 회수할 수 있다 | `관찰` |

> **검증 방법**: 같은 구간을 총기만으로 한 번, 활과 암살만으로 한 번 통과하고 **다음 구간 시작 시점의 소지 자원**을 비교하면, 두 통화의 환율이 실제로 존재하는지 판정할 수 있다.

## 6. 플레이 루프

**이 게임의 루프는 크기가 다른 두 개다.** `관찰`
하나만 보면 절반이 빠진다.

```
[작은 사이클 — 한 전투]           [큰 사이클 — 게임 전체]
적 발견                            탐색
  ↓                                 ↓
상황 판단                          스토리
  ↓                                 ↓
전투                               전투
  ↓                                 ↓
자원 소비                          자원 관리
  ↓                                 ↓
(다음 적)                          스토리 → 탐색
```

처음에 세운 구조는 이랬다.

```
탐색 → 자원 획득 → 적 발견 → 상황 판단 → 은신 / 전투 선택 → 자원 소비 → 다음 공간
```

**그런데 실제 플레이와 두 곳이 어긋난다.** `관찰`

| 처음 세운 것 | 실제 |
|---|---|
| 탐색 구간과 전투 구간이 나뉜다 | **나뉘지 않는다.** 탐색 중에 적을 발견한다 |
| 은신과 전투를 자유롭게 고른다 | **강제되는 전투가 있다** |

수정한 구조는 이렇다.

```
탐색 → 자원 획득 → 스토리 진행 → 적 발견 → 상황 판단 → 전투
→ 자원 소비 → 적 처치 → 자원 획득 → 다음 공간
```

**전투는 독립적인 반복 콘텐츠가 아니라, 이야기를 진행하는 과정에 결합된 구간이다.** `추론`

## 7. Problem Chaining

이 게임의 체인은 **전투 안과 전투 사이에 각각 하나씩** 있다. `추론`

**전투 안에서**

```
적을 발견한다 → 종류를 확인한다 (클리커인가 인간인가)
→ 조용히 갈지 정한다 → 그러려면 어느 자원을 쓸지 정한다
→ 실패하면 소음이 발생한다 → 몰려온 적을 다시 처리해야 한다
```

**전투 사이에서**

```
이 구간을 총으로 밀었다 → 탄약이 줄었다
→ 다음 구간은 조용히 가야 한다 → 그러려면 제작 재료가 필요하다
→ 그래서 더 뒤져야 한다 → 뒤지려면 위험한 공간에 들어가야 한다
```

**바깥 체인이 이 게임의 성격을 만든다.** `추론`

| 게임 | 체인이 이어지는 범위 |
|---|---|
| [Katana ZERO](./KatanaZERO.md) | 방 하나 안에서 닫힌다 |
| [Shadow Tactics](./ShadowTactics.md) | 미션 하나가 통째로 한 체인이다 |
| **The Last of Us Part I** | **소지품을 통해 게임 전체가 이어진다** |

인벤토리가 초기화되지 않기 때문에 **전투가 서로 연결된다.** `추론`
한 전투를 잘 푸는 것과 게임을 잘 푸는 것이 같지 않은 이유가 여기에 있다.

## 8. 제거 / 변경 분석

[Sleeping Dogs](./SleepingDogs.md)의 5개 층위에, [BioShock Infinite](./BioShockInfinite.md)에서 붙인 **`중심축을 돕는가`** 단계를 함께 적용한다.

### ① 맵 구석구석에 배치된 아이템

스토리 진행에 필요하지 않은 공간까지 탐색하게 만든다. `관찰`
그래서 처음에는 불필요한 배회를 만드는 요소로 봤다.

| 층위 | 해당 여부 |
|---|---|
| 핵심 게임플레이 | **그렇다** |
| 성장 시스템 | 그렇다 — 제작 재료가 곧 전투 수단이다 |
| 공간 / 세계 경험 | 그렇다 — 뒤지는 행위가 폐허를 폐허로 만든다 |

**중심축 검사에서 판정이 뒤집힌다.** `추론`

이 게임의 중심축이 `생존`이라면, **뒤져서 모으는 행위 자체가 생존의 절반이다.**
자원을 조여 놓고 주울 곳까지 없애면 5번의 판단 구조가 성립하지 않는다.

> 배회처럼 느껴지는 것과 기능이 없는 것은 다르다. `추론`

다만 **불편함 자체는 실재한다.** 이것은 [Hollow Knight](./HollowKnight.md)에서 정리한
`개인적 불편함 ≠ UX 문제`와 같은 자리이며, 불편이 만드는 것이 있으므로 제거 후보는 아니다.

### ② 의미가 약한 수집 요소

지도나 일부 스토리 수집 요소는 진행에 필수적이지 않다. `관찰`
다만 스토리를 더 깊게 이해하려는 플레이어에게 정보를 준다. `관찰`

| 층위 | 해당 여부 |
|---|---|
| 핵심 게임플레이 | 아니다 |
| 공간 / 세계 경험 · 장식 / 분위기 | **그렇다** |

따라서 결론은 `불필요`가 아니라

> **핵심 게임플레이에는 필요하지 않은 부가 요소**

다. [Sleeping Dogs](./SleepingDogs.md)의 부가 활동과 같은 판정이다. `추론`

### 두 항목의 차이

| | 처음 판단 | 판정 후 |
|---|---|---|
| 맵 구석 아이템 | 배회를 만든다 | **핵심에 가깝다** — 중심축이 생존이므로 |
| 수집 요소 | 없어도 된다 | 부가 요소 — 서사 이해를 돕는다 |

**같은 `없어도 진행된다`인데 결론이 갈린다.** `추론`
앞의 것은 중심축을 직접 떠받치고, 뒤의 것은 옆에서 보탠다.

> 죽을 것 같을 때쯤 아이템을 제공해서 숨을 돌리게 하는 구조인가?

**분석 후에는 다르게 본다.** `추론`

> 위험을 계속 올리면서 자원은 조인 채로 두고, 그 상태로 통과하게 만든다.
> 그 끝에 남는 것이 **"이 상황에서 살아남았다"**는 감각이다.

| | 생존감을 만드는 방식 |
|---|---|
| 처음 생각 | 위기 때 자원을 **주는** 타이밍 설계 |
| 수정한 생각 | 위험을 **누적**시키고 자원을 조이는 구조 |

전자는 안도를 만들고 후자는 **통과했다는 감각**을 만든다. `추론`
그리고 이 감각이 스토리 진행과 붙어 있기 때문에, 여정의 무게로 옮겨간다.

**③ 외부 근거**

없다. 따라서 ②는 여기서 멈춘다.

## 10. 기획자로서 배울 점

### ① 처음 세운 프레임에 게임을 끼워 맞추지 않는다

이번 분석의 실제 산출물이다.

`탐색 → 전투`로 나눠 놓고 보니 **실제 플레이에서는 그 경계가 없었다.** `관찰`
탐색 중에 적을 만나고, 전투가 강제되는 구간도 있다.

> 프레임이 안 맞을 때 고칠 것은 게임이 아니라 프레임이다.

[BioShock Infinite](./BioShockInfinite.md)에서 얻은 `분석 프레임에도 중심축이 있다`와 이어지지만 층이 다르다. `추론`

| | 어긋난 것 |
|---|---|
| BioShock Infinite | 질문의 **순서** |
| **The Last of Us Part I** | 구조의 **경계선** |

### ② 큰 사이클과 작은 사이클을 나눠 본다

한 전투만 보면

```
적 발견 → 판단 → 전투 → 자원 소비
```

이지만, 게임 전체를 보면

```
탐색 → 스토리 → 전투 → 자원 관리 → 스토리 → 탐색
```

이다.

**작은 사이클만 보면 서사가 담당하는 층이 통째로 빠진다.** `추론`
반대로 큰 사이클만 보면 전투 안의 판단이 사라진다. 두 배율을 다 봐야 한다.

### ③ 자원은 보상이 아니라 제한 장치일 수 있다

```
자원이 보상이면   → 많이 얻는 것이 목표가 된다
자원이 제한이면   → 적게 쓰는 것이 목표가 된다
```

후자로 설계하면 질문이 바뀐다. `추론`

> `죽일 수 있는가` → **`이 방법으로 죽여도 되는가`**

**같은 전투인데 실행의 문제에서 판단의 문제로 옮겨간다.**

### ④ 통화를 두 개 두면 선택이 입체가 된다

물자와 소음이 그것이다.

수단마다 두 통화의 비율이 다르기 때문에, 무기 선택이 **위력 비교가 아니라 지불 방식의 선택**이 된다. `추론`

| 통화가 하나일 때 | 통화가 둘일 때 |
|---|---|
| 무엇이 제일 센가 | 지금은 무엇을 아껴야 하는가 |

[Papers, Please](./PaperPlease.md)의 `서로를 잡아먹는 두 자원`과 형태는 같지만,
이쪽은 두 통화가 **한 행동에서 동시에 지불된다**는 점이 다르다. `추론`

### ⑤ 비용을 도구로 쓸 수 있게 하면 시스템이 한 겹 깊어진다

소음은 보통 치르는 값이다. 그런데 투척물은 **소음을 일부러 만들어 적을 옮긴다.** `관찰`

> 페널티로 설계한 것에 **능동적인 사용처**를 하나 열어 주면, 플레이어가 그것을 자원으로 다시 읽는다. `추론`

### ⑥ 배치를 고정하면 반복이 학습이 된다

적 배치가 고정되어 있어서 반복 플레이가 **공간 퍼즐**이 된다. `관찰`

무작위 배치는 매번 신선하지만 **남는 것이 없다.** `추론`
고정 배치는 두 번째부터 지루해질 위험이 있지만, 대신 플레이어의 학습이 자산으로 쌓인다.

[Hitman](./Hitman.md)에서 정리한 `예측 가능성은 계획의 전제조건이다`와 같은 지점이다.

### ⑦ 생존감은 주는 타이밍이 아니라 누적으로 만든다

9번에서 판단이 바뀐 부분이다.

```
위기 때 자원을 준다   → 안도감
위험을 누적시킨다     → 통과했다는 감각
```

**살아남았다는 느낌은 여유를 준 순간이 아니라, 여유가 없는 채로 끝까지 간 뒤에 온다.** `추론`
