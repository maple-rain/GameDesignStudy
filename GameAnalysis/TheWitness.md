# The Witness 게임 분석

## 1. 게임 개요
- 장르: 퍼즐 어드벤처
- 핵심 경험: 플레이어 스스로 규칙을 발견하고 이해하는 과정

## 2. Core Experience

명시적인 설명 없이 환경과 퍼즐을 통해 학습하고 성장하는 경험이 핵심입니다.

## 3. 재미 요소 분석

- 규칙 발견의 즐거움
- 관찰과 추론
- 새로운 관점으로 기존 문제를 다시 보는 경험

## 4. 핵심 메커닉 분석

| 메커닉 | 설명 | 재미와 연결점 |
|---|---|---|
| 선 연결 퍼즐 | 규칙을 찾아 해결 | 발견 기반 학습 |
| 환경 단서 | 주변 요소 활용 | 자연스러운 튜토리얼 |

## 5. 플레이 루프

관찰 → 가설 생성 → 실험 → 규칙 발견 → 새로운 문제 해결

## 6. Problem Chaining

플레이어가 스스로 질문을 만들도록 설계한 대표적인 문제 체이닝 사례입니다.

## 7. 제거/변경 분석

환경 단서와 단계적 학습 구조가 사라지면 단순 퍼즐 풀이가 됩니다.

## 8. 디자이너 의도 추론

플레이어가 가르침을 받는 것이 아니라 발견하도록 만드는 설계입니다.

## 9. 기획자로서 배울 점

튜토리얼 없이도 플레이어가 규칙을 학습하는 UX 설계를 배울 수 있습니다.
