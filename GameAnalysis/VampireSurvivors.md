# Vampire Survivors 게임 분석

## 1. 재미를 주는 요소

### 성장 루프

Vampire Survivors는 단순한 조작을 기반으로 하지만 지속적인 성장과 조합을 통해 강한 성취감을 제공한다.

핵심 흐름:

1. 적 처치
2. 경험치 획득
3. 레벨업
4. 새로운 무기 선택
5. 조합 완성
6. 더 강한 성장 경험

### 아이템 조합

개별 아이템보다 여러 아이템이 조합되었을 때 발생하는 시너지와 폭발적인 성장감이 주요 재미 요소다.

## 2. 제거했을 때의 변화

성장 선택 요소가 제거되면 단순 반복 플레이가 되며, 플레이어가 다음 목표를 기대하는 동기가 약해진다.

## 3. 핵심 메커닉

| 메커닉 | 설명 |
|---|---|
| 자동 공격 | 조작 부담을 낮추고 성장에 집중 |
| 경험치 성장 | 지속적인 강화 경험 제공 |
| 아이템 선택 | 플레이어의 전략적 선택 제공 |
| 조합 시스템 | 장기 목표와 기대감 형성 |

## 4. 디자이너 의도

간단한 조작 구조에서도 성장, 선택, 보상 루프를 통해 강한 몰입 경험을 만드는 것.
