# Failure Design

실패를 어떻게 설계하는가에 대한 연구.

---

## 1. 왜 별도 항목인가

게임 분석을 19개 진행하면서, 좋은 평가를 받은 게임들이 공통적으로
**실패를 처벌이 아니라 다른 무엇으로 바꿔놓았다**는 것을 알게 되었다.

이 관점은 [Reward Loop](./RewardLoop.md)로는 설명되지 않는다.
보상 루프는 "잘했을 때 무엇을 주는가"를 다루지만,
플레이어가 실제로 대부분의 시간을 보내는 쪽은 실패다.

> **실패는 루프의 예외가 아니라 루프의 절반이다.**

---

## 2. 실패 설계의 4가지 축

분석한 게임들을 비교하면 네 가지 축으로 정리된다.

| 축 | 질문 |
|---|---|
| 실패 비용 | 실패하면 무엇을 잃는가? |
| 원인 가독성 | 왜 실패했는지 알 수 있는가? |
| 실패의 산출물 | 실패해서 무엇을 얻는가? |
| 재시작 지연 | 다시 시도하기까지 몇 초 걸리는가? |

### 게임별 비교

| 게임 | 실패 비용 | 원인 가독성 | 실패의 산출물 | 재시작 지연 |
|---|---|---|---|---|
| Celeste | 없음 | 매우 높음 | 조작 정확도 | 1초 미만 |
| Katana ZERO | 없음 | 매우 높음 | 그 방의 적 배치와 타이밍 | 거의 없음 |
| INSIDE | 없음 | 높음 | 위험 정보 | 매우 짧음 |
| Return of the Obra Dinn | 없음 | 낮음 | (없음) | 즉시 재시도 |
| The Witness | 없음 | 중간 | 규칙 가설의 반증 | 즉시 |
| Outer Wilds | 획득물 상실 | 중간 | 지식 (영구) | 루프 단위 |
| Hollow Knight | 소지 자원 상실 | 높음 | 보스 패턴 | 벤치까지 이동 |
| Slay the Spire | 런 전체 | 낮음~중간 | 카드·유물 이해 | 새 런 시작 |
| Vampire Survivors | 런 전체 | 낮음 | 메타 성장 재화 | 새 런 시작 |
| Disco Elysium | 없음 | 높음 | **실패 전용 대사와 상황** | 즉시 (실패해도 진행) |

이 표에서 드러나는 것이 있다.
**실패 비용이 낮은 게임일수록 원인 가독성이 높다.**
둘은 독립 변수가 아니라 한 쌍으로 설계된다.

---

## 3. 실패 비용과 원인 가독성은 한 쌍이다

### 낮은 비용 + 높은 가독성 — Celeste

- 입력 반응이 즉각적이다
- 실패 원인이 명확하다
- 판정이 일관적이다
- 성공이 플레이어 실력의 결과처럼 느껴진다

그래서 수십 번 죽더라도 "게임이 억울하게 만들었다"보다
**"내가 조금 더 정확하게 하면 된다"**는 감각이 유지된다.

> 실패의 책임이 자신에게 있다는 납득이 곧 재도전 동력이다.

### 낮은 비용 + 정보 획득 — INSIDE

| 단계 | 내용 |
|---|---|
| 행동 | 플레이어가 위험한 구간에 아무 정보 없이 진입한다. |
| 규칙 | 접촉하면 즉사하지만, 체크포인트가 바로 앞에 있어 즉시 재시작된다. |
| 결과 | 실패 비용이 낮으므로 플레이어는 실험을 반복해 규칙을 학습한다. |
| 감정 | 죽는 것이 처벌이 아니라 정보 획득으로 느껴진다. |

**설명 없는 학습과 낮은 실패 비용은 한 쌍이다.**
튜토리얼을 없애면서 실패 비용을 높이면, 학습이 아니라 스트레스가 된다.

### 높은 비용 + 낮은 가독성 — 주의해야 하는 조합

Slay the Spire는 런 전체를 잃는데, 무엇 때문에 졌는지가 즉시 보이지 않는다.
20층에서의 패배 원인이 3층의 카드 선택일 수 있기 때문이다.

이 조합이 성립하는 이유는 **실패가 곧 학습 자료**이고,
플레이어가 그 인과를 스스로 재구성하는 것이 이 게임의 재미이기 때문이다.
즉 **높은 비용 + 낮은 가독성은 그 재구성 자체가 재미일 때만 성립한다.**

## 4. 처벌하지 않는 것도 설계다

### Return of the Obra Dinn

이 게임은 오답 자체를 처벌하지 않는다.
게임오버도 없고 패널티도 없다.

하지만 진실을 찾지 못하면 다음 정보를 얻을 수 없고, 스토리를 완전히 복원할 수도 없다.

> **외부적인 패널티 대신 플레이어의 호기심 자체를 진행 동력으로 사용한다.**

처벌을 추가하면 플레이어가 가설을 세우는 것을 두려워하게 된다.
현재 구조는 실패 비용이 낮기 때문에 적극적으로 추론을 시도할 수 있다.
**처벌의 부재가 곧 설계다.**

### 다만 무제한 시행착오는 막아야 한다

Obra Dinn은 처벌하지 않으면서도 찍기를 막는다.
**3명의 운명이 동시에 정확할 때만 확정 처리**되기 때문이다.

이것이 실패 설계의 정교한 지점이다.

| 목표 | 수단 |
|---|---|
| 가설 시도를 장려한다 | 오답에 패널티를 주지 않는다 |
| 찍기를 막는다 | 확정 조건을 묶어서 확신을 요구한다 |

처벌 없이 신중함을 만들어냈다.

### 처벌을 없애는 것과 실패에 내용을 주는 것은 다르다

[Disco Elysium](../GameAnalysis/DiscoElysium.md)은 한 걸음 더 간다.
스킬 체크에 실패해도 진행이 막히지 않는데, **실패한 경로에만 나오는 대사와 상황이 따로 있다.**

| | 실패했을 때 |
|---|---|
| Obra Dinn | 아무 일도 일어나지 않는다 (처벌의 부재) |
| **Disco Elysium** | **다른 내용이 나온다 (실패의 서사화)** |

전자는 실패를 **무해하게** 만들고, 후자는 실패를 **선택지의 하나로** 만든다.
후자에서는 세이브 로드로 성공을 강요할 이유가 약해진다.
실패해도 손해가 아니라 다른 것을 본 것이기 때문이다.

> **실패에 내용을 주면 실패가 콘텐츠가 된다.**

---

## 5. 오답도 설계 대상이다

좋은 퍼즐은 정답만 있는 것이 아니라 **그럴듯한 오답**이 있다.

Portal 2에서 플레이어는 종종 버튼 위에 계속 서 있어 보고, 큐브를 던져 보고,
다른 벽에 포탈을 쏴 본다.

> **오답을 시도하는 과정 자체가 규칙 학습이 된다.**

즉 실패가 낭비가 아니라 메커닉 이해 과정이 된다.

The Witness는 이 구조를 가장 순수하게 사용한다.

```
가설을 세우고 → 시도하고 → 실패하고 → 다시 관찰하고 → 규칙을 발견한다
```

여기서 실패는 **가설의 반증**이라는 산출물을 남긴다.
반증이 쌓이면 규칙의 형태가 좁혀진다.

---

## 6. 실패가 자원이 되는 구조 — Outer Wilds

가장 극단적인 사례다.

이 게임은 **소모되는 자원(루프당 시간)과 축적되는 자원(지식)을 분리**했다.

| 게임 | 실패 시 |
|---|---|
| Celeste | 대시를 쓰면 없어진다. 실패하면 위치가 되돌아간다 |
| Slay the Spire | 에너지를 쓰면 없어진다. 실패하면 런이 끝난다 |
| Outer Wilds | 시간을 다 쓰면 되돌아가지만, **지식은 남는다** |

| 단계 | 내용 |
|---|---|
| 행동 | 플레이어가 한 지역을 탐사하다 루프 종료 시점을 맞는다. |
| 규칙 | 세계가 초기화되며 획득물과 위치는 되돌아가지만, 이해한 내용은 남는다. |
| 결과 | 실패가 손실이 아니라 다음 루프의 계획 재료가 된다. |
| 감정 | 초기화의 무력감보다 "이번엔 저기로 바로 간다"는 계획 욕구가 앞선다. |

**소모 자원과 축적 자원을 분리하면 플레이어가 위험을 감수하게 만들 수 있다.**

---

## 7. 실패에 비용이 있어야 하는 경우

실패를 무료로 만드는 것이 항상 정답은 아니다.

### Hollow Knight

사망 시 소지한 소울을 잃고, 그 자리로 돌아가 회수해야 한다.
또한 회복은 소울을 소비하고 시전 시간이 필요하므로 전투 중 실패 위험을 감수해야 한다.

| 단계 | 내용 |
|---|---|
| 행동 | 회복을 시도한다. |
| 규칙 | 소울을 소비하며 일정 시간 동안 움직임이 제한된다. |
| 결과 | 플레이어는 안전한 타이밍을 직접 만들어야 한다. |
| 감정 | 욕심을 부리면 회복이 끊기고 피해를 입지만, 성공하면 강한 안도감을 느낀다. |

여기서 실패 비용은 **긴장감을 만드는 장치**다.
비용을 없애면 모든 전투가 판단 없는 반복이 된다.

### 판단 기준

| 목표 | 실패 비용 |
|---|---|
| 학습시키고 싶다 | 낮춘다 |
| 긴장시키고 싶다 | 높인다 |
| 숙련시키고 싶다 | 낮추고 원인 가독성을 극대화한다 |
| 신중하게 만들고 싶다 | 비용 대신 확정 조건을 묶는다 |

## 8. 재시작 지연이 곧 난이도다

같은 난이도라도 재시작까지 걸리는 시간이 체감 난이도를 바꾼다.

- Celeste: 1초 미만 → 수십 번 죽어도 루프가 끊기지 않는다
- Katana ZERO: 거의 없음 → 한 대에 죽는데도 처벌로 느껴지지 않는다
- Hollow Knight: 벤치까지 이동 → 죽음이 무겁게 느껴진다
- 로그라이크: 새 런 시작 → 실패가 세션 단위 사건이 된다

**난이도 조절 수단을 적의 체력에서만 찾을 필요가 없다.**
체크포인트 간격과 재시작 지연이 더 강력한 조절 손잡이일 수 있다.

### 같은 즉사라도 재시작 지연이 성격을 뒤집는다

[Katana ZERO](../GameAnalysis/KatanaZERO.md)가 이 축을 가장 선명하게 보여준다.
대부분의 공격이 한 대에 사망인데도, 난이도가 처벌로 느껴지지 않는다.

```
즉사 + 긴 재시작    → 처벌
즉사 + 즉시 재시작  → 학습
```

피격 판정은 두 경우가 같다. 다른 것은 재시작 지연뿐이다.

> **즉사는 난이도를 정하지 않는다. 난이도를 정하는 것은 다시 시도하기까지 걸리는 시간이다.**

그래서 `한 대에 죽는다`는 규칙을 난이도 설정으로 읽으면 틀린다.
그 규칙이 실제로 하는 일은 **시도 한 번을 짧게 잘라 회전 속도를 올리는 것**이다.

같은 이유로 이 게임에서는 실패가 정보로 바뀐다.
잃는 것이 시간뿐이므로, 죽음이 남기는 것은 손실이 아니라 **그 방의 적 배치와 타이밍**이다.

Celeste의 보조 모드는 이 관점을 시스템으로 만든 사례다.
게임 속도, 대시 횟수, 무적, 스태미너 무한, 스테이지 건너뛰기를 조절할 수 있게 하여
**난이도를 고정값이 아니라 플레이어가 조절 가능한 변수**로 만들었다.

## 9. 분석 체크리스트

- [ ] 실패하면 무엇을 잃는가? (시간 / 자원 / 진행 / 아무것도)
- [ ] 왜 실패했는지 플레이어가 알 수 있는가?
- [ ] 실패로 무엇을 얻는가? (정보 / 숙련 / 재화 / 없음)
- [ ] 재시작까지 몇 초 걸리는가?
- [ ] 실패 비용과 원인 가독성의 조합이 의도된 것인가?
- [ ] 설명을 생략했다면 실패 비용을 함께 낮췄는가?
- [ ] 처벌 없이 신중함을 요구할 방법이 있는가?
- [ ] 실패가 처벌로 느껴지는가, 정보로 느껴지는가?
