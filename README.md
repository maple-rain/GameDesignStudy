## Analysis Framework

게임을 다음 기준으로 분석합니다.

1. 게임의 핵심 경험 파악
2. 재미를 제공하는 요소 분석
3. 핵심 메커닉 파악
4. 플레이 루프 분석
5. 문제 체이닝 구조 분석
6. 제거했을 때 발생하는 변화
7. 디자이너 의도 추론
8. 기획자로서 적용할 점 정리
