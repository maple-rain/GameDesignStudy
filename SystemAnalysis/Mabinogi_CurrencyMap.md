# 마비노기 모바일 — 재화 구조 분석

> **분석 기간**: 2025-11-24 ~ 2026-01-15 (약 2개월)
> **분석 대상**: 게임 내 전체 재화의 획득처 · 사용처 · 상품 카탈로그
> **산출물**: 7시트 / 1,000행 이상의 재화 카탈로그
> **상태**: 카탈로그 완성, 수급 속도 미측정 — **분석 설계를 재수립한 문서**

---

## 1. 조사 방법

### 1단계 — 분류 체계 수립 (2025-11-24)

상품부터 모으지 않고 **재화 종류를 최상위로 두고 갈래를 뻗는 하향식**으로 시작했다.

```
마비노기 모바일 › 재화
├ M캐시 ─ 패키지 (이벤트 / 횟수 / 토탈 / 포인트 / 연속 / 미션 / 월간 / 주간 / 클래스)
│         멤버십 (판타지라이프토탈 / 라이프 / 던전크롤러 / 모험가)
├ 데카 ── 거래소, 장비 구매, 아이템 구매, 도구 구매, 데카 패키지, 데카 샵
├ 골드 ── 조각난 보석 보물 상자
└ 현금 패키지 ─ 스타터 / 고양이 / 패션티켓 / 프리미엄 패션티켓
```

### 2단계 — 상품 단위 전개 (2025-11-25 ~ 11-26)

각 패키지를 열어 **구성품과 수량까지** 기록했다. 하루 만에 노드 33개 → 238개로 확장.

> 예: 월간 프리미엄 패션 티켓 패키지 → `미가공 데카 원석 490개` + `프리미엄 패션 티켓 40개`
> 스페셜 리워드 → 구매 1회차부터 8회차까지 각 보상 전개

### 3단계 — 엑셀 이관 시 축을 재편 (2025-11-27 ~)

마인드맵은 `재화 → 상품` 트리 하나였으나, 엑셀에서는 **두 개의 축으로 나눴다.**

**축 A — 재화를 행으로**

```
구분 | 종류 | 속성 | 유료 구매 가능 | 무료 획득 가능 | 사용처 | 설명
```

유료/무료 획득 가능 여부를 **O/X 교차**시킨 것이 핵심이다. 재화의 성격이 한눈에 드러난다.

**축 B — 상품을 행으로**

| 시트 | 내용 | 행수 |
|---|---|---|
| 2. 골드 | 골드로 구매 가능한 상품 | 225 |
| 3. 골드 제외 무료 재화 | 그 외 무료 재화로 구매 가능한 상품 | 239 |
| 4. 주력 유료 재화 상품 | 유료 재화 상품 + 현금 가치 | 184 |
| 5. 기타 유료 재화 상품 | 유료 재화 상품 + 현금 가치 | 90 |
| 구매 가능 상품 | 재화별 병렬 배치 | 312 × 45열 |

`구매 횟수` 열을 처음부터 넣은 것이 중요하다. `주간 3회`, `주간 10회` 같은 제한이 곧 유량 상한이기 때문이다.

### 4단계 — 현금 환산 기준 확립 (2025-12 ~ 2026-01)

| 구매 목록 | 가격 | 현금 가치 |
|---|---|---|
| 모험가 패스 프리미엄 티켓 | 1,980 | 19,800원 |
| 미가공 데카 원석 10개 | 100 | 1,000원 |

**M캐시 1 = 10원**이라는 환산자를 확보했다.

## 2. 재화 구조 — 이 게임은 경제를 두 개로 나눴다

O/X 교차표를 한 단계 추상화하면 재화의 성격이 드러난다.

| 재화 | 유저간 거래 | 현금 구매 | 현금화 | 유형 |
|---|---|---|---|---|
| **골드** | X | O | X | 폐쇄형 — 개인 경제 안에서만 순환 |
| **데카** | **O** | O | X | 거래형 — 유저간 경제를 형성 |
| **M캐시** | X | — | 유입점 | 하드 커런시 |
| 하트 토큰 | X | X | X | 순수 무료 |

> **개인 경제(골드)와 유저간 경제(데카)가 분리되어 있다.**
> 골드는 NPC 상점 전용이라 인플레이션이 유저 사이로 전파되지 않고, 거래는 데카가 전담한다.

이 분리는 소프트 커런시의 가치 붕괴를 막는 구조다. 골드가 아무리 흔해져도 유저간 시세에 영향을 주지 않는다.

## 3. 과금 유도 지점 — 패키지 구성품 빈도

> **패키지에 반복해서 들어가는 아이템 = 게임사가 "부족하다"고 판단한 재화**

마인드맵의 패키지 구성품을 집계하면 추가 조사 없이 병목이 드러난다.

| 아이템 | 등장 패키지 |
|---|---|
| 미가공 데카 원석 | 월간 패션티켓 · 월간 펫티켓 · 월간 인첸트증폭 · 월간 강화촉매 · 월간 연금술촉매 · 월간 골든데이즈 · 주간 패션티켓 · 주간 펫티켓 · 주간 각인강화 · 주간 보석 |
| 강화 재연소 촉매 | 토탈 · 월간 강화촉매 · 출석 리턴 |
| 연금술 재연소 촉매 | 토탈 · 월간 연금술 · 출석 리턴 (고급/레어/엘리트/에픽 4등급) |
| 룬의 파편 | 토탈 · 출석 리턴 · 주간 각인강화 · 클래스 |

**촉매류와 미가공 원석이 압도적이다.**
이 게임의 과금 유도는 **장비 강화와 연금술 구간**에 집중되어 있다.

강화 재연소 촉매는 강화를 1회 더 시도할 수 있게 해주는 **재시도권**이다.
확률 시스템의 완화 상품이며, [로스트아크 재련 분석](./LostArk_Refining_SWOT.md)의
`장인의 기운`과 같은 계열의 장치다.

## 4. 이 분석에서 빠진 것

카탈로그는 완성되었으나 한 축이 통째로 비어 있다.

| 조사한 것 | 빠진 것 |
|---|---|
| 이 재화를 **어디서** 얻는가 | 하루에 **얼마나** 얻는가 |
| 이 재화로 **무엇을** 살 수 있는가 | 그걸 사려면 **며칠** 걸리는가 |
| 유료 재화의 현금 가치 | **무료 재화의** 현금 가치 |

`사냥터, 기타`, `퀘스트, 거래소, 업적` 같은 획득처는 모두 기록되어 있으나 **수치가 없다.**
그래서 재고(상품 목록)는 완벽한데 유량(획득 속도)이 없어 결론이 나오지 않는 상태였다.

이 문제를 인식한 것이 두 달 뒤의 [젠레스 존 제로 분석](./ZZZ_GrowthCurve.md)이다.
그쪽은 정확히 반대로, 유량을 측정하고 재고가 부족했다.

| | 마비노기 | 젠레스 존 제로 |
|---|---|---|
| 재고 (카탈로그) | **완비** | 부분 |
| 유량 (획득 속도) | 없음 | **완비** |
| 환산 기준 | 있음 (M캐시 1 = 10원) | 있음 (배터리 1pt = 10exp) |
| 결론 | 나오지 않음 | 나옴 |

## 5. 재수립한 분석 설계

### 핵심 질문

> **무과금 유저의 하루 플레이는 골드 기준 얼마의 현금 가치를 갖는가?**

### 대상 재화 — 골드 단독

전체 재화 40여 종을 모두 측정하는 대신 **골드 하나로 범위를 좁혔다.**

| 재화 | 채택 여부 | 사유 |
|---|---|---|
| **골드** | **채택** | 폐쇄형이라 유입·유출이 닫혀 있어 측정이 안정적. 소모처 225행이 이미 완비. 게임 내 M캐시 구매 경로가 있어 공식 환율이 존재 |
| 데카 | 제외 | **이벤트 지급 비중이 크다.** 시작 시점에 따라 수급량이 달라져 재현이 불가능하다 |
| 강화 재연소 촉매 | 보류 | 확률 시스템과 묶어야 의미가 남는다. 별도 분석으로 분리 |
| M캐시 | 축이 아닌 **환산자**로 사용 | 골드를 원으로 바꾸는 경로 |

**환산 경로**

```
골드 일일 수급 → (게임 내 골드 구매 가격) → M캐시 → × 10원 → 하루의 현금 가치
```

환율을 추정할 필요가 없다. 게임사가 골드를 M캐시로 판매하고 있으므로 **게임사가 매긴 값**을 읽으면 된다.

### 주목할 점 — 골드 구매에는 주간 상한이 있다

`Sheet1`에 골드는 `M캐시를 통해서 일정 횟수 주간마다 구매 가능`으로 기록되어 있다.
무제한이 아니다.

> 게임사가 골드를 무제한 판매하지 않는다는 것은,
> **돈으로 시간을 사는 데 상한을 걸었다**는 뜻이다.
> 그 상한값이 곧 게임사가 허용한 과금 격차의 최대치다.

### 진행 단계

| 단계 | 내용 | 추가 측정 |
|---|---|---|
| 0 | 재화 성격 분류표 (거래 / 구매 / 현금화 3축) | 없음 — 기존 O/X 표에서 도출 (2장) |
| 0-b | 패키지 구성품 빈도 → 병목 진단 | 없음 — 마인드맵에서 도출 (3장) |
| 1 | 골드 공식 환율 + 주간 구매 상한 | 없음 — 4·5번 시트에서 추출 |
| 2 | **골드 일일 무과금 수급** | **여기만 측정** |
| 3 | 하루의 현금 가치 / 소모처 225행 = 며칠치 | 계산 |

3단계에서 `2. 골드` 시트 225행 전체가 "무과금 며칠치"로 환산되며,
그 부담 곡선이 꺾이는 지점이 과금 압박 구간이 된다.

### 범위를 좁힌 이유

전체 재화를 다루지 않은 것은 미완성이 아니라 판단이다.

> 폐쇄형 재화 하나로 범위를 좁히면 이벤트·거래 같은 외부 변수를 제거할 수 있고,
> 그만큼 결론의 재현 가능성이 올라간다.
> 데카처럼 이벤트 지급 비중이 큰 재화는 "언제 시작한 유저인가"에 따라 결과가 달라져
> 같은 방법으로 다시 측정해도 같은 값이 나오지 않는다.
