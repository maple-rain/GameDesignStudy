# TIL - Disco Elysium : 선택의 의미를 결과만으로 판단하면 안 된다

> 분석일: 2026-08-10 (분석 순서 14)
> 관련 분석: [Disco Elysium](../../GameAnalysis/DiscoElysium.md)

## 1. 오늘 분석한 게임

**Disco Elysium**

오픈월드 추리 RPG이자 포인트 앤 클릭 어드벤처에 가까운 게임.
일반적인 RPG처럼 전투와 성장에 집중하기보다는 대화, 선택, 스킬, 내면의 목소리 등을 통해
**주인공이라는 인물을 만들어가는 경험**에 초점을 맞춘 게임으로 보았다.

특히 24개의 스킬이 단순한 능력치가 아니라 각각 하나의 인격 또는 내면의 목소리처럼 작동한다는 점이 특징적이다.

## 2. 핵심 경험

Disco Elysium의 핵심은 사건을 해결하는 것 자체보다
**사건을 해결해가는 과정에서 플레이어가 자신만의 주인공을 만들어가는 것**이라고 판단했다.

플레이어는 스킬을 선택하고, 대화에서 선택지를 고르고, 스킬 체크를 수행하면서
주인공의 사고방식과 행동을 만들어간다.

따라서 일반적인 RPG의

```
성장 → 강해짐 → 전투 → 클리어
```

와는 다른 방향의 경험을 제공한다. 오히려

```
선택 → 경험 → 실패/성공 → 새로운 정보 → 또 다른 선택
```

이라는 흐름에 가깝다.

## 3. 재미 요소

### ① 주인공의 내면을 직접 경험하는 것

스킬이 단순한 숫자가 아니라 각각 하나의 인격처럼 작동한다.
플레이어가 상황을 바라볼 때 특정 스킬이 말을 걸어오고, 플레이어는 그 목소리에 귀를 기울일지 선택하게 된다.

따라서 **캐릭터의 능력치가 곧 캐릭터의 성격과 사고방식으로 연결된다.**

### ② 실패가 게임오버가 되지 않는 것

스킬 체크에서 실패하더라도 게임이 끝나는 것이 아니다.
실패 역시 새로운 대화나 상황을 만들어내는 하나의 경험이 된다.

즉, `실패 = 진행 불가`가 아니라 **`실패 = 다른 형태의 콘텐츠`**로 작동한다.

이는 이전에 분석했던 [Return of the Obra Dinn](../../GameAnalysis/ReturnOfTheObraDinn.md)의
'오답에 대한 무처벌'과도 연결해서 생각할 수 있었다.

### ③ 방대한 대화와 정보

주인공의 과거와 사건의 진상뿐만 아니라 NPC들의 과거와 생각까지 방대한 양의 정보가 존재한다.
한 번의 플레이만으로 모든 정보를 경험하기 어렵기 때문에 플레이어마다 서로 다른 경험을 할 수 있다.

### ④ 비효율적인 플레이도 경험이 되는 구조

효율적으로 사건을 해결하는 것만이 목표가 아니다.
헤매거나 실패하거나 예상하지 못한 선택을 하는 것 역시 게임의 경험으로 만들어진다.

따라서 플레이어에게 **"가장 효율적인 선택"을 강요하지 않는 것**이 특징적이다.

## 4. 행동 메커닉

플레이어가 직접 수행하는 행동을 기준으로 분류했다.

- 이동
- NPC와 대화
- 사물 조사
- 선택지 선택
- 스킬 포인트 분배
- 사고(Thought) 습득 및 관리
- 인벤토리 사용
- 일지 확인
- 상호작용 가능한 대상 탐색

## 5. 시스템 메커닉

이번 분석에서 가장 어려웠던 부분.
Disco Elysium에서는 플레이어의 행동과 시스템이 굉장히 밀접하게 연결되어 있어 단순히 분리하기 어려웠다.

| 시스템 | 내용 |
|---|---|
| 스킬 체크 | 스킬 능력치와 주사위 결과를 이용해 행동의 성공과 실패를 결정한다 |
| 스킬의 인격화 | 스킬이 단순한 능력치가 아니라 주인공의 내면의 목소리로 등장한다 |
| 선택에 따른 대화 변화 | 플레이어의 선택과 캐릭터의 스킬 구성에 따라 대화와 상황이 달라진다 |
| 실패의 서사화 | 스킬 체크 실패가 게임오버가 아니라 새로운 이야기로 이어진다 |
| 사고 시스템 | 특정 사고를 받아들이고 발전시키면서 캐릭터의 상태와 대화에 영향을 준다 |
| 정보에 따른 선택지 변화 | 이전에 얻은 정보나 경험에 따라 새로운 대화 선택지가 등장한다 |

## 6. 플레이 루프

Disco Elysium은 전형적인 RPG의 전투 중심 루프와 상당히 다르다.

```
탐색
  ↓
NPC 및 환경과 상호작용
  ↓
정보 획득
  ↓
선택
  ↓
스킬 체크 / 결과
  ↓
새로운 정보와 상황 발생
  ↓
다시 탐색 및 선택
```

여기에서 **실패조차 루프를 중단시키지 않고 새로운 경험으로 편입한다**는 점이 중요하다.

## 7. Problem Chaining

Disco Elysium에서는 문제를 해결하면 바로 다음 문제로 넘어가는 구조보다는
**정보가 새로운 문제와 선택지를 만들어내는 방식**이 강하게 나타난다.

예를 들어,

```
NPC와 대화
  ↓
새로운 정보를 획득
  ↓
기존 사건을 다른 관점에서 바라봄
  ↓
새로운 질문 발생
  ↓
다른 NPC 또는 장소 조사
  ↓
새로운 정보 획득
```

처럼 정보가 계속 연결된다.

따라서 문제 체이닝이 단순히

```
문제 A → 해결 → 문제 B
```

가 아니라,

```
정보 A → 해석 B → 새로운 의문 C → 정보 D → 새로운 해석
```

으로 확장되는 형태라고 볼 수 있다.

## 8. 없어도 되는 요소

### 실질적인 영향을 주지 않는 선택지

처음에는 "선택과 결과가 동일한 선택지는 필요 없는 요소"라고 판단했다.

다만 분석하면서 **결과가 같다는 사실만으로 불필요하다고 판단해서는 안 된다**는 점도 확인했다.
결과가 같더라도 해당 선택이

- 새로운 정보를 제공하거나
- 캐릭터의 관계를 변화시키거나
- 스킬/페르소나에 영향을 주거나
- 새로운 대화를 만들어내거나
- 플레이어가 자신의 캐릭터를 정의하는 경험을 제공한다면

의미가 있을 수 있다.

반대로,

```
선택 → 동일한 결과 → 새로운 정보 없음 → 캐릭터 변화 없음 → 이후 상황 변화 없음
```

이라면 실질적으로 플레이어가 경험하는 차이가 없기 때문에 불필요한 선택지로 볼 수 있다고 판단했다.

특히 Disco Elysium처럼 **선택과 페르소나 형성 자체를 중요한 경험으로 삼는 게임**에서는
이러한 문제가 더욱 크게 느껴질 수 있다.

## 9. 오늘 새롭게 배운 것

### "선택지가 많다"와 "의미 있는 선택이 많다"는 다르다

게임에 수많은 선택지가 존재한다고 해서 플레이어에게 수많은 의미 있는 선택을 제공하는 것은 아니다.

따라서 선택지를 분석할 때는 단순히 분기의 개수를 세는 것이 아니라,

> **"이 선택이 플레이어의 경험을 실제로 변화시키는가?"**

를 확인해야 한다.

### 행동 메커닉과 시스템 메커닉의 경계가 항상 명확한 것은 아니다

Disco Elysium에서는

```
대화 → 선택 → 스킬 체크 → 인격의 개입 → 성공/실패 → 새로운 대화
```

가 하나의 연결된 시스템으로 작동한다.

따라서 어떤 행동이 시스템 메커닉인지 단순히 행동의 종류만 보고 판단하기보다는,

> **"플레이어의 행동을 게임이 어떤 규칙으로 처리하여 새로운 경험으로 만드는가?"**

를 기준으로 판단해야 한다.

## 10. 디자이너 의도 추론

오늘 분석을 통해 내가 추측한 개발 의도는 다음과 같다.

> **"플레이어에게 정답을 찾게 하는 것이 아니라, 자신의 선택과 실패를 통해 하나의 인격을 경험하게 한다."**

조금 더 풀어보면, Disco Elysium은 플레이어가 완벽하게 효율적인 선택을 하여 사건을 해결하도록 만드는 게임이라기보다
**수많은 내면의 목소리와 선택, 성공과 실패를 경험하면서 자신만의 주인공을 만들어가는 게임**이라고 생각한다.

## 11. 오늘의 핵심

오늘 가장 크게 배운 것은 **게임에서 '선택'의 의미를 결과만으로 판단하면 안 된다**는 것이다.

하지만 동시에,

> 결과도 변하지 않고, 정보도 변하지 않고, 캐릭터도 변하지 않고, 이후 경험도 변하지 않는다면
> 그 선택은 정말 필요한가?

라는 질문 역시 할 수 있다.

결국 중요한 것은 선택지의 개수가 아니라, **선택이 플레이어의 경험을 변화시키는가**이다.

이번 분석은 내가 지금까지 해왔던 "없어도 되는 요소 찾기"를 한 단계 발전시켜,
**요소 자체가 아니라 그 요소가 플레이어 경험에 기여하는지를 판단해야 한다**는 것을 배운 분석이었다.
