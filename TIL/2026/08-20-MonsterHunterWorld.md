# TIL - Monster Hunter: World : 같은 행동의 반복과 같은 경험의 반복은 다르다

> 분석일: 2026-08-20 (분석 순서 20)
> 관련 분석: [Monster Hunter: World](../../GameAnalysis/MonsterHunterWorld.md)

## 1. 오늘의 핵심 질문

> 몬스터 헌터에서 반복 사냥은 왜 재미있는가?

처음에는 단순히

```
몬스터 사냥 → 소재 획득 → 장비 제작 → 더 강한 몬스터 사냥
```

이라는 파밍 루프를 생각하기 쉽다.

하지만 이번 분석에서 조금 더 중요한 부분을 발견했다.

몬스터 헌터의 반복은 같은 행동을 반복하는 것이 아니라,

> **같은 몬스터를 대상으로 플레이어가 더 나은 해결 방법을 찾아가는 반복**

에 가깝다.

## 2. 행동 메커닉

- 이동
- 대시 / 구르기
- 일반 공격 및 무기별 공격
- 콤보
- 아이템 사용
- 아이템 제작
- 소재 채취
- 흔적 조사
- 퀘스트 수주
- 퀘스트 클리어
- 몬스터 사냥
- 몬스터 포획
- 환경 및 지형 활용

특히 **무기마다 공격 방식과 커맨드가 크게 달라서** 플레이어가 자신의 무기에 적응하는 과정 자체가 숙련 요소가 된다.

## 3. 시스템 메커닉

- 퀘스트 수주
- 몬스터 탐색
- 흔적 조사
- 몬스터 발견
- 몬스터 패턴 관찰
- 약점 공략
- 부위 파괴
- 그로기
- 몬스터 처치 / 포획
- 소재 획득
- 장비 제작 및 강화
- 스킬 세팅
- 식사
- 아이템 제작
- 반복 사냥

이를 하나의 구조로 정리하면:

```
퀘스트 수주 → 탐색 → 흔적 조사 → 몬스터 발견 → 관찰 → 약점 공략
→ 사냥 → 보상 → 장비 강화 → 더 어려운 사냥
```

이라는 순환 구조가 만들어진다.

## 4. 몬스터는 하나의 '문제'가 된다

몬스터 헌터의 핵심 재미는 단순히 몬스터의 HP를 0으로 만드는 것이 아니다.

플레이어는 몬스터를 관찰하면서

- 어떤 공격을 하는지
- 언제 빈틈이 생기는지
- 어느 부위가 약한지
- 어떤 공격을 피해야 하는지
- 어떤 상태이상이나 속성이 효과적인지
- 어떤 장비가 효과적인지

등을 알아간다.

따라서 기본적인 구조는

```
관찰 → 분석 → 준비 → 사냥 → 실패 → 수정 → 재도전
```

으로 볼 수 있다.

이 점은 이전에 분석했던 [Katana ZERO](./08-18-KatanaZERO.md)의

```
관찰 → 계획 → 실행 → 실패 → 수정
```

과도 연결된다.

하지만 몬스터 헌터는 여기에 **성장과 장비 커스터마이징**이 추가된다.

그리고 몬스터 하나를 단순한 적으로 보는 것보다 **하나의 문제**로 보는 것이 더 적절하다고 생각했다.

```
몬스터 발견
  ↓
패턴 파악
  ↓
약점 파악
  ↓
공격 기회 확보
  ↓
공격
  ↓
몬스터의 행동 변화
  ↓
다시 대응
```

따라서 몬스터 헌터의 사냥은 **실시간으로 진행되는 문제 해결 과정**이라고 볼 수 있다.

## 5. 플레이어는 캐릭터뿐만 아니라 '자신'도 성장시킨다

오늘 특히 중요하게 느껴진 부분이다.

몬스터 헌터에서 장비를 강화하면 실제 캐릭터의 능력치가 상승한다.
하지만 그것만으로 강해지는 것은 아니다.

플레이어 역시

- 몬스터의 패턴을 기억하고
- 공격 타이밍을 익히고
- 회피 타이밍을 익히고
- 자신의 무기 사용법을 익히고
- 효율적인 콤보를 연구한다.

즉,

> **캐릭터 성장 + 플레이어 숙련**

두 가지 성장이 동시에 일어난다.

그래서 강한 몬스터를 처음에는 20분 동안 겨우 잡았는데, 나중에는 같은 몬스터를 훨씬 안정적으로 잡게 되는 경험이 생긴다.

처음에는 몬스터에게 일방적으로 맞지만, 반복해서 사냥하면서

- 공격 패턴
- 빈틈
- 약점
- 공격 타이밍
- 회피 타이밍
- 부위 파괴 방법

등을 알아간다.

결과적으로 **플레이어가 점점 몬스터에게 적응한다.**

## 6. 플레이어가 실제로 만드는 것은 무엇인가?

이번 분석에서 가장 중요한 질문이었다.

처음에는 장비와 빌드를 생각할 수 있다.
하지만 더 넓게 보면 플레이어는 세 가지를 만든다.

### ① 장비 조합

어떤 무기와 방어구, 스킬을 사용할 것인가?

### ② 사냥 방법

어떤 공격을 사용하고 어떤 타이밍에 공격할 것인가?
무기와 장비, 아이템, 함정 등을 조합해서 자신만의 공략법을 만든다.

### ③ 몬스터에 대한 지식

> "이 몬스터는 이렇게 행동한다."

라는 자신만의 이해를 만든다.

**특히 세 번째가 중요하다고 생각했다.**

처음에는 몬스터에게 끌려다니지만,

> "이 공격 다음에는 반드시 이 빈틈이 생긴다."

라는 식으로 몬스터의 행동을 이해하면서 플레이어 자신이 숙련된다.

따라서 몬스터 헌터의 가장 중요한 성장 중 하나는 **수치적 성장보다 지식의 성장**이라고 볼 수 있다.

## 7. 사냥 방법에 선택지가 존재한다

오늘 발견한 또 하나의 재미는 **몬스터를 반드시 죽일 필요가 없다는 것**이다.

전투 중에는

- 직접 공격
- 부위 파괴
- 상태이상
- 함정
- 포획

등 여러 방법을 사용할 수 있다.

따라서 목표가

> "몬스터를 죽인다."

에서

> "몬스터를 어떻게 처리할 것인가?"

로 확장된다.

이런 선택지가 있기 때문에 플레이어는 자신의 준비와 상황에 따라 다른 해결 방법을 선택할 수 있다.

즉 **어떤 요소를 어떻게 활용해서 잡을지 고민하는 것 또한 재미**다.

## 8. '월드'는 단순히 맵이 큰 것이 아니다

오늘 처음에 적었던

> "사냥하는 곳은 오픈월드인가?"

라는 질문도 꽤 좋은 질문이었다.

Monster Hunter: World의 맵은 일반적인 의미의 오픈월드와는 다르다.
중요한 것은 맵의 크기보다 **생태계와 탐색이 사냥과 연결되어 있다는 점**이다.

예를 들어 플레이어는 흔적을 찾고,

```
흔적 → 몬스터의 위치 추적 → 조우 → 사냥
```

으로 이어지는 과정을 경험한다.

따라서 월드는 단순한 이동 공간이 아니라 **사냥을 위한 정보가 존재하는 공간**으로 기능한다.

## 9. 반복 사냥이 '숙제'로 변하는 순간도 존재한다

하지만 모든 반복이 재미있는 것은 아니다.

몬스터 헌터의 장비 파밍은 때때로

> "원하는 소재가 나올 때까지 같은 몬스터를 계속 잡는다."

라는 숙제처럼 느껴질 수 있다.

특히 종결 세팅을 만들기 위해 여러 몬스터의 장비를 조합해야 하는 경우에는 플레이어가 직접 최적의 세팅을 찾기보다는 **공략을 검색하게 된다.**

여기서 재미의 성격이 달라진다.

| | 질문 |
|---|---|
| 플레이어가 스스로 만드는 것 | "이 몬스터를 어떻게 잡을까?" |
| 공략을 찾아서 따라가는 것 | "이 몬스터에게 가장 좋은 세팅은 무엇인가?" |

이 둘은 상당히 다르다.

따라서 **빌드 다양성이 있다고 해서 반드시 플레이어의 창의성이 발생하는 것은 아니다.**

### 재미있는 반복과 숙제의 차이

| | 플레이어의 말 |
|---|---|
| 재미있는 반복 | "이번에는 이 방법으로 잡아볼까?" |
| 숙제가 되는 반복 | "원하는 소재가 나올 때까지 또 잡아야 한다." |

둘 다 같은 몬스터를 반복해서 잡는 행동이지만 플레이어가 느끼는 경험은 다르다.

따라서

> **학습을 위한 반복**과 **보상을 얻기 위한 반복**은 구분할 필요가 있다.

플레이어가 이미 몬스터를 충분히 이해했는데도 단순히 소재 때문에 반복하게 된다면, 반복은 도전이 아니라 **노동**으로 느껴질 수 있다.

## 10. 필요 없다고 느낀 요소

이번에는 몇 가지가 명확하게 보였다.

### ① 불필요하게 긴 멀티플레이 진입 과정

스토리를 먼저 진행한 뒤 멀티플레이에 들어가야 하는 구조는 멀티플레이를 목적으로 하는 플레이어에게 불필요한 마찰이 될 수 있다.

이후 시리즈에서 개선되었다는 점을 보면 실제 UX상의 문제였다고 볼 여지가 있다.

### ② 조라 마그다라오스의 일부 진행

거대한 몬스터를 상대한다는 연출 자체는 게임의 규모감을 보여주지만,

- 지나치게 긴 플레이 시간
- 반복적인 대포 사용
- 작살 사용
- 광맥 파밍
- 각종 버그

등은 "거대한 몬스터를 상대한다"는 핵심 경험에 비해 재미가 부족한 부분으로 보인다.

즉,

> **컨셉에 필요한 요소와 실제 플레이에서 재미있는 요소는 항상 일치하지 않는다.**

이것은 오늘 분석에서 꽤 중요한 발견이다.

## 11. 개발자 의도 추론

몬스터 헌터는 단순히 강한 몬스터를 쓰러뜨리는 게임이라기보다,

> **몬스터를 관찰하고 이해하고 공략하는 재미**

를 중심에 둔 게임이라고 생각한다.

넓은 필드 역시 단순히 큰 공간을 제공하기 위한 것이 아니라,

```
몬스터의 흔적을 찾고 → 위치를 추적하고 → 생태를 파악하고 → 사냥한다
```

는 과정을 만들기 위한 공간으로 볼 수 있다.

## 12. 오늘 배운 것

Monster Hunter: World의 반복 사냥은 단순한 파밍 루프가 아니다.

표면적으로는

```
사냥 → 소재 → 장비 → 더 강한 사냥
```

이지만, 플레이어 경험에서는

```
관찰 → 이해 → 준비 → 사냥 → 숙련 → 새로운 공략법 발견
```

이라는 또 하나의 루프가 존재한다.

그리고 **이 두 루프가 결합하면서 반복 사냥이 성립한다.**

### 오늘 배운 게임 기획 개념

> **반복 = 같은 행동을 반복시키는 것 ≠ 같은 경험을 반복시키는 것**

좋은 반복 구조에서는 플레이어가 같은 콘텐츠를 다시 플레이하더라도 플레이어의

- 지식
- 숙련도
- 장비
- 목표
- 공략법

이 변화한다.

그래서 같은 몬스터를 다시 만나도 **첫 번째 사냥과 열 번째 사냥은 다른 경험**이 될 수 있다.

## 오늘의 핵심 인사이트

> **몬스터 헌터는 몬스터를 반복해서 잡게 하는 게임이 아니라, 같은 몬스터를 더 잘 이해하고 더 잘 잡게 되는 과정을 반복하게 만드는 게임이다.**

그리고 오늘 가장 큰 발전은 이것이다.

> 게임에 어떤 콘텐츠가 있는지를 **나열하는 것**에서 벗어나, 그 콘텐츠를 반복하면서 플레이어가 무엇을 **학습하고 만들어가는지**를 분석하기 시작했다.
