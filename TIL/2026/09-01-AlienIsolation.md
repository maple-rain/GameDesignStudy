# TIL - Alien: Isolation : 안전하다고 확신할 수 없다는 것이 공포다

> 분석일: 2026-09-01 (분석 순서 28)
> 관련 분석: [Alien: Isolation](../../GameAnalysis/AlienIsolation.md)

## 1. 게임의 핵심

**1인칭 호러 서바이벌 어드벤처**

이 게임의 핵심은 적을 쓰러뜨리는 것이 아니라,

> 안드로이드, 생존자, 그리고 특히 **죽일 수 없는 에일리언**을 피해 목표를 달성하는 것

이다.

특히 에일리언의 존재 때문에 플레이어는 게임 내내 **은밀한 이동과 위험 관리**를 요구받는다.

## 2. 행동 메커닉

### 이동

- 걷기
- 달리기
- 웅크리기
- 기어가기

### 상호작용

- 문 열기
- 아이템 획득
- 장치 조작
- 주변 조사

### 생존

- 숨기
- 적 회피
- 모션 트래커 사용

### 장비

- 무기 사용
- 투척물 사용
- 아이템 선택
- 아이템 제작

특히 **이동 자체가 소음과 연결되어 있다는 점**이 중요하다.

```
달린다 → 소리가 난다 → 적에게 위치가 노출될 가능성이 증가한다
```

따라서 플레이어의 기본 이동부터 이미 생존 시스템에 연결되어 있다.

## 3. 시스템 메커닉

이번 게임의 기본적인 반복 구조는:

```
탐색 → 자원 획득 → 자원을 기반으로 제작 → 위험 발생 → 회피 / 대응 → 목표 달성
```

으로 정리할 수 있다.

여기서 중요한 것은 **위험에 대응하는 방법이 전투에 한정되지 않는다**는 것이다.

플레이어는 상황에 따라

- 숨는다.
- 걷거나 기어서 이동한다.
- 모션 트래커로 주변을 확인한다.
- 소리를 이용해 에일리언을 유인한다.
- 아이템을 사용한다.
- 위험 지역을 우회한다.

등의 행동을 선택한다.

## 4. 이 게임은 플레이어가 들키지 않기 위해 어떤 행동을 하도록 만드는가?

### ① 소리

```
달리기 → 소음 발생 → 에일리언에게 위치가 노출될 가능성 증가
```

따라서 플레이어는 자연스럽게 걷거나 기어가는 행동을 선택하게 된다.

즉, **단순한 이동 조작이 잠입 행동을 유도하는 시스템으로 연결된다.**

### ② 모션 트래커

모션 트래커는 주변 적의 접근을 파악할 수 있는 중요한 장비다.

따라서 플레이어는

> "지금 주변에 적이 있는가?"

를 지속적으로 확인하면서 이동하게 된다.

다만 이것 역시 만능 해결책이 아니라, **플레이어가 주변 상황을 판단하기 위한 정보 제공 수단**으로 사용된다.

### ③ 아이템

노이즈메이커나 화염방사기 등의 아이템을 이용해 에일리언의 행동을 유도하거나 일시적으로 쫓아낼 수 있다.

하지만 자원이 제한되어 있기 때문에 모든 상황에서 사용할 수 없다.

따라서:

```
위험 발생 → 아이템 사용 여부 판단 → 자원 소비
```

라는 판단이 발생한다.

## 5. 에일리언 AI가 만드는 플레이

이번 분석에서 가장 중요한 부분.

에일리언은 단순히 정해진 경로를 순찰하는 적이 아니라, **플레이어의 행동에 대응하며 추적하는 존재**로 인식된다.

예를 들어

```
섬광탄을 던진다 → 에일리언이 그것을 관찰한다 → 이후 비슷한 행동에 대응한다
```

와 같은 경험이 발생한다면, 플레이어 입장에서는 **단순한 패턴 암기가 어려워진다.**

따라서 플레이어는

> "전에 이렇게 했으니까 이번에도 통하겠지."

라는 판단을 계속 의심하게 된다.

이것이 에일리언을 단순한 장애물이 아니라 **예측하기 어려운 위협**으로 만든다.

### 다만 확정하지 않는다

직접 확인해 보면 AI가 항상 완벽하게 플레이어를 추적하는 것은 아니다.
소리가 발생했음에도 제대로 찾지 못하거나, 문이 열리고 닫히는 소리를 듣고도 적극적으로 조사하지 않는 경우도 존재한다.

따라서 여기서는 "완벽하게 학습하는 AI"라고 확정하기보다는,

> **플레이어에게 그렇게 느껴지는 예측 불가능성과 대응 행동을 만들어내는 AI**

정도로 정리하는 것이 안전하다.

## 6. 왜 플레이어는 반복해서 숨는가?

가장 직접적인 이유는:

> **에일리언을 근본적으로 제거할 수 없기 때문이다.**

다른 적을 죽일 수 있는 상황이 존재하더라도, 에일리언까지 전투로 해결할 수 있는 수단은 제한적이다.

따라서 플레이어에게는 결국

```
숨기 → 이동 → 발각 위험 → 대응 → 다시 숨기
```

라는 행동이 반복된다.

여기에 자원 제한까지 결합되면서 무작정 도구를 사용하는 것도 어렵다.

결국 플레이어는 **에일리언을 없애는 방법이 아니라 에일리언을 상대하는 방법**을 계속 만들어야 한다.

## 7. 플레이어가 만들어내는 것

이번 게임에서 플레이어가 만들어내는 것은 **안전한 이동 방법과 에일리언을 유도하는 방법**이라고 볼 수 있다.

예를 들어:

- 어떤 경로로 이동할 것인가?
- 언제 움직일 것인가?
- 언제 숨을 것인가?
- 소리를 내서 에일리언을 어디로 유도할 것인가?
- 제한된 아이템을 언제 사용할 것인가?
- 모션 트래커를 언제 확인할 것인가?

즉, **플레이어 자신만의 생존 패턴**을 만들어내게 된다.

## 8. 공포는 무엇으로 만들어지는가?

오늘 추가한 핵심 질문:

> **"이 게임은 플레이어에게 공포를 느끼게 하기 위해 어떤 시스템을 이용하는가?"**

핵심은 **에일리언의 행동에 대한 불확실성**이다.

플레이어는 에일리언을 계속 의식해야 한다.
하지만 에일리언이 정확히 어디에 있는지 항상 알 수 있는 것도 아니고, 내가 사용한 방법이 다음에도 통할 것이라고 확신할 수도 없다.

여기에 모션 트래커와 페이스 허거가 결합된다.
에일리언에게 모든 신경을 집중하고 있는 순간에도 다른 위협이 등장할 수 있기 때문에 **플레이어는 한 가지 위험에만 집중할 수 없다.**

결과적으로 공포는 단순히

> "무서운 에일리언이 나타난다."

가 아니라,

> **"내가 지금 안전하다고 확신할 수 없다."**

에서 발생한다고 볼 수 있다.

## 9. 세이브 시스템

고전적인 세이브 방식도 긴장감을 만드는 요소로 볼 수 있다.

세이브에 몇 초의 시간이 필요하기 때문에 위험한 상황에서는 안전하게 저장할 수 없다.

따라서

```
세이브 지점 발견 → 주변 확인 → 안전 확보 → 세이브
```

라는 행동이 발생한다.

**세이브 자체가 단순한 편의 기능이 아니라 위험 관리의 일부**가 된다.

## 10. 오늘의 핵심 정리

오늘 분석에서 가장 중요한 연결은 이것이다.

```
소리
  ↓
적의 관심을 유발
  ↓
은밀한 이동 필요
  ↓
모션 트래커로 위험 확인
  ↓
에일리언 발견
  ↓
숨기 / 도망 / 유인 / 아이템 사용
  ↓
자원 소비 또는 위험 감수
  ↓
다시 탐색
```

결국 **하나의 시스템이 플레이어의 다음 행동을 만들어내고, 그 행동이 다시 다음 시스템과 연결된다.**

## 오늘의 핵심 인사이트

> **Alien: Isolation은 에일리언을 처치하는 방법을 제공하는 게임이 아니라, 처치할 수 없는 존재를 상대로 매 순간 새로운 생존 방법을 만들어내게 하는 게임이다.**
