# TIL - DEATHLOOP : 플레이어의 지식이 곧 성장 요소가 된다

> 분석일: 2026-09-02 (분석 순서 29)
> 관련 분석: [DEATHLOOP](../../GameAnalysis/Deathloop.md)

## 1. 오늘의 게임

**DEATHLOOP**

핵심 질문:

> **"플레이어의 지식이 어떻게 게임의 성장 요소가 되는가?"**

DEATHLOOP은 일반적인 RPG처럼 캐릭터의 능력치만 성장하는 게임이 아니라, **플레이어가 루프를 반복하며 얻은 정보와 경험 자체가 성장 요소**가 되는 게임이라고 볼 수 있다.

## 2. 행동 메커닉

플레이어가 직접 수행하는 행동은 다음과 같다.

- 이동 / 달리기 / 걷기 / 웅크리기 / 점프
- 사격 / 조준
- 근접 공격 및 암살
- 슬랩 능력 사용
- 해킹
- 투척
- 아이템 사용
- 환경 상호작용
- 적 태깅
- 장비 및 무기 교체

특히 중요한 것은 단순히 적을 공격하는 것보다 **주변 환경과 장비를 이용해 상황을 만들어내는 것**이다.

예를 들어:

```
적을 직접 죽인다
→ 해킹으로 장치를 이용한다
→ 함정을 설치한다
→ 특정 장소로 적을 유도한다
→ 다른 NPC와 함께 제거한다
```

즉, **플레이어가 사용할 수 있는 도구가 많고, 이를 어떤 상황에서 사용할지는 플레이어가 결정한다.**

## 3. 시스템 메커닉

DEATHLOOP의 핵심 구조는 **하루의 반복**이다.

### 기본 구조

```
하루의 반복
  ↓
정보 획득
  ↓
새로운 접근 방법 발견
  ↓
목표 제거
  ↓
루프 반복
  ↓
더 많은 정보와 장비 확보
  ↓
효율적인 암살 방법 구축
```

특히 일반적인 게임처럼

```
경험치 → 레벨업 → 능력치 상승
```

이라는 성장 구조에만 의존하지 않는다.

대신,

```
플레이어의 지식 → 더 나은 판단 → 더 효율적인 행동
```

이라는 성장 구조가 핵심이다.

## 4. 플레이어는 무엇을 학습하는가?

루프를 반복하면서 다음과 같은 정보를 축적한다.

- 적의 위치
- NPC의 행동
- 시간대에 따른 사건
- 지형
- 목표의 이동 경로
- 암살 방법
- 장비의 활용법
- 특정 사건을 발생시키는 조건
- 특정 목표들을 동시에 처리할 수 있는 방법

예를 들어 처음에는

> "이 사람을 어떻게 죽이지?"

라고 생각했다면, 몇 번의 루프 이후에는

> "이 시간에 이 장소에서 이 사건을 발생시키면 두 명을 동시에 처리할 수 있겠는데?"

로 사고가 바뀐다.

즉, **플레이어가 게임의 규칙을 이해할수록 같은 공간에서도 새로운 가능성이 발생한다.**

## 5. 왜 같은 장소를 반복해서 방문해도 지루하지 않은가?

DEATHLOOP에서는 **공간 자체보다 공간에서 발생하는 사건과 조건**이 중요하다.

같은 장소라도

- 시간대가 다르고
- NPC의 행동이 달라지고
- 목표가 달라지고
- 플레이어가 가진 장비가 달라지고
- 이전 루프에서 얻은 정보가 추가되면서

전혀 다른 상황으로 접근할 수 있다.

따라서

> 같은 맵을 반복한다 = 같은 플레이

가 아니다.

오히려 플레이어가 정보를 축적하면서

> "이번에는 여기서 이걸 해보자."

라는 새로운 실험을 할 수 있게 된다.

## 6. 스토리 자체가 거대한 퍼즐

DEATHLOOP의 독특한 부분은 **스토리의 진행 조건 자체가 하나의 퍼즐처럼 구성되어 있다**는 점이다.

목표가 되는 인물들은 특정 시간과 장소에서만 모습을 드러내거나 특정 조건에서만 행동한다.
따라서 단순히 한 명씩 찾아가 죽이는 것으로 끝나지 않는다.

최종적으로는 **여러 목표를 한 루프 안에서 제거해야 하기 때문에**,

```
목표 A의 행동
+ 목표 B의 행동
+ 시간대
+ 장소
+ 플레이어의 개입
```

을 조합해야 한다.

결국 플레이어가 풀어야 하는 것은 단순한 암살 퍼즐이 아니라,

> **"하루라는 제한된 시간 안에서 여러 사건을 어떻게 연결할 것인가?"**

라는 거대한 퍼즐이다.

## 7. 죽음은 실패인가?

DEATHLOOP에서 죽음은 일반적인 게임의 실패와 조금 다르다.

죽음 이후 루프가 반복되기 때문에 플레이어는 **이전의 경험을 가지고** 다시 시작한다.

따라서

```
죽음 → 실패 → 처음부터
```

가 아니라,

```
죽음 → 정보 획득 → 새로운 방법 발견 → 다음 루프에서 적용
```

이라는 구조가 만들어진다.

특히 선지자들을 한 번에 모두 제거하지 못하면 루프가 다시 진행되는 구조 때문에, **죽음과 반복 자체가 게임의 진행 구조와 연결된다.**

## 8. 플레이어가 만들어내는 것은 무엇인가?

플레이어가 직접 만들어내는 것은 **효율적인 암살 루트와 상황**이다.

예를 들어:

- 안전한 이동 루트
- 목표를 제거하는 방법
- NPC를 이용한 암살 방법
- 장비 조합
- 능력 활용 방법
- 자원 사용 우선순위
- 여러 목표를 동시에 처리하는 방법

즉 개발자가 모든 암살 방법을 직접 만들어 놓았다기보다는,

> **개발자가 시스템과 규칙을 제공하고, 플레이어가 그 규칙을 조합하여 사건을 만들어낸다.**

## 9. 장비 시스템과 성장

무기와 트링켓에는 등급과 특성이 존재한다.
이를 통해 루프를 반복하면서 더 좋은 장비를 확보하고, 자신의 플레이 스타일에 맞는 장비 구성을 만들어갈 수 있다.

따라서 **두 가지 성장 축**이 존재한다고 볼 수 있다.

| 성장 축 | 내용 |
|---|---|
| 플레이어의 성장 | 정보와 경험의 축적 |
| 캐릭터의 성장 | 무기 / 트링켓 / 능력 확보 |

하지만 DEATHLOOP에서 특히 중요한 것은 **플레이어의 지식이 캐릭터 성장보다 더 직접적으로 플레이를 변화시킨다**는 점이다.

## 10. 오늘의 핵심 분석

오늘 분석에서 가장 중요했던 부분은 이것이다.

> **"플레이어의 지식이 어떻게 게임의 성장 요소가 되는가?"**

일반적인 게임에서는

```
레벨 상승 → 능력치 증가 → 더 강한 적 상대
```

라는 방식으로 성장한다.

DEATHLOOP에서는

```
반복 → 정보 획득 → 이해 → 새로운 접근 → 성공
```

이라는 방식으로 성장한다.

처음에는 목표를 죽이는 방법을 몰라서 실패한다.
하지만 반복하면서

> "이 NPC는 이 시간에 여기로 간다."
>
> "이 사건이 발생하면 저 NPC가 움직인다."
>
> "이 장비를 사용하면 이 경로를 이용할 수 있다."

라는 지식을 얻는다.

그리고 다음 루프에서 그 지식을 활용한다.

따라서 **플레이어가 강해지는 것이 아니라, 플레이어가 게임을 더 잘 이해하게 되면서 강해지는 구조**라고 볼 수 있다.

## 오늘의 핵심 인사이트

> **DEATHLOOP은 반복을 통해 캐릭터의 능력만 성장시키는 것이 아니라, 플레이어에게 정보를 축적시키고 그 정보를 활용해 기존의 공간과 사건을 새로운 방식으로 재구성하게 만드는 게임이다.**

그리고 이 관점에서 보면 DEATHLOOP의 핵심 재미는 단순한 "타임 루프"가 아니라,

> **"처음에는 불가능해 보였던 일을, 정보를 충분히 얻은 뒤 완벽한 계획으로 실행하는 것"**

에 있다고 정리할 수 있다.
