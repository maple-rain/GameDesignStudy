# TIL - Death Stranding : 이동을 다음 콘텐츠로 가는 수단이 아니라 핵심 액션으로

> 분석일: 2026-09-09 (분석 순서 34)
> 관련 분석: [Death Stranding](../../GameAnalysis/DeathStranding.md)

## 1. 오늘의 게임

**Death Stranding**

오늘은 일반적인 액션 게임에서 이동이 어떤 역할을 하는지와, 데스 스트랜딩이 **이동 자체를 어떻게 핵심 게임플레이로 만들어냈는지**를 분석했다.

### 오늘의 핵심 질문

> **"Death Stranding은 단순한 이동을 어떻게 핵심 게임플레이로 만드는가?"**

그리고 한 단계 더 들어가서:

> **"게임이 플레이어에게 이동 경로와 물류 문제를 어떻게 해결하게 만드는가?"**

## 2. 기본적인 플레이 구조

데스 스트랜딩의 기본적인 플레이 흐름은 다음과 같이 정리할 수 있다.

```
목적지 확인
→ 지형 및 장애물 파악
→ 이동 경로 선택
→ 화물 및 장비 관리
→ 이동
→ 장애물 대응
→ 배송 완료
→ 장비 / 인프라 확보
→ 다음 이동의 효율 증가
```

일반적인 오픈월드 게임에서 이동은 **다음 콘텐츠로 넘어가기 위한 과정**인 경우가 많다.
하지만 데스 스트랜딩에서는 **이동 과정 자체에 여러 판단과 행동을 요구한다.**

따라서 플레이어는 단순히 "목적지까지 간다"가 아니라,

> **"어떤 경로로 어떻게 이동할 것인가?"**

를 계속 고민하게 된다.

## 3. 행동 메커닉

주요 행동 메커닉은 다음과 같다.

- 걷기
- 달리기
- 점프
- 등반
- 화물 운반
- 장비 사용
- 차량 이용
- 로프 및 사다리 설치
- 구조물 설치

겉으로 보면 일반적인 게임에서도 존재하는 행동들이지만, 데스 스트랜딩에서는 이 행동들이 **이동이라는 하나의 문제를 해결하기 위해 결합된다.**

예를 들어 험난한 지형에서는 단순히 앞으로 움직이는 것만으로 해결할 수 없다.

```
지형을 확인
→ 건널 수 있는 위치 판단
→ 사다리 / 앵커 사용
→ 화물 균형 유지
→ 이동
```

과 같은 행동이 필요하다.

결과적으로 **이동 자체가 하나의 액션 콘텐츠가 된다.**

## 4. 이동을 게임플레이로 만드는 방법

데스 스트랜딩의 가장 중요한 특징은 **지형을 이동 과정의 장애물로 적극적으로 활용한다**는 점이다.

산, 강, 절벽, 경사 등의 지형이 단순한 배경이 아니라 **플레이어가 해결해야 하는 문제**가 된다.

따라서 플레이어는 자연스럽게 다음과 같은 판단을 하게 된다.

> "이 길로 바로 갈 것인가?"
>
> "돌아서 안전한 길로 갈 것인가?"
>
> "장비를 사용해서 직선으로 넘어갈 것인가?"
>
> "화물을 더 가져가서 한 번에 배송할 것인가?"

이 과정에서 **이동 경로 자체가 플레이어의 선택 영역**이 된다.

## 5. 화물 시스템

데스 스트랜딩은 일반적인 게임의 인벤토리와 달리 **화물을 실제 물리적인 짐처럼 취급한다.**

화물에는 무게와 부피 등이 존재하고, 샘의 몸에 실제 박스 형태로 적재된다.

따라서 단순히

> "아이템이 몇 개 있는가?"

가 아니라

> **"얼마나 많은 짐을 어떤 방식으로 운반할 것인가?"**

가 중요한 문제가 된다.

짐이 많아지거나 무게 중심이 무너지면 이동 중 균형을 잃을 수 있으며, 넘어질 경우 화물에 손상이 발생한다.
이를 방지하기 위해 플레이어는 이동 중 균형을 잡아야 한다.

즉 화물 시스템은 단순한 인벤토리 제한이 아니라 **이동에 직접 영향을 주는 물류 시스템**으로 기능한다.

## 6. 플레이어가 선택해야 하는 것

화물과 지형을 결합하면 플레이어에게 여러 선택이 발생한다.

### 화물

> 얼마나 많은 물건을 가져갈 것인가?

많이 가져가면 한 번에 더 많은 물건을 운반할 수 있지만, 이동이 불편해진다.

### 이동 경로

> 가장 빠른 길인가, 가장 안전한 길인가?

직선으로 이동할 경우 험난한 지형을 통과해야 할 수 있고, 돌아가는 길은 오래 걸리지만 안전할 수 있다.

### 장비

> 어떤 장비를 가져갈 것인가?

사다리나 앵커 등의 장비를 준비하면 이동이 쉬워지지만 **그만큼 운반해야 할 물건이 늘어난다.**

### 전투

> 싸울 것인가, 피할 것인가?

배송 과정에서 전투를 선택할 수도 있지만, 배송 효율이나 화물 상태 등을 고려하면 전투 자체가 항상 최선의 선택은 아니다.

결국 플레이어는

```
속도 / 안전 / 화물량 / 장비 / 위험
```

사이에서 자신의 선택을 하게 된다.

## 7. 배송 평가의 역할

배송에는 평가 시스템이 존재하기 때문에 플레이어는 단순히 목적지에 도착하는 것만 생각하지 않게 된다.

얼마나 효율적으로 배송했는가, 화물을 얼마나 잘 보존했는가 등의 요소가 플레이 경험에 영향을 준다.

따라서 배송 평가 시스템은 플레이어에게

> "목적지에 도착하는 것"뿐만 아니라 **"어떻게 도착할 것인가"**

를 고민하게 만드는 장치라고 볼 수 있다.

이 때문에 싸움을 무조건 선택하기보다, 상황에 따라 전투를 피하는 것이 더 좋은 선택이 될 수 있다.

## 8. 진행에 따른 이동 방식의 변화

초반에는 주로 도보 이동과 사다리, 앵커 등을 활용한다.

하지만 진행하면서

- 차량
- 도로
- 집라인
- 각종 건설물

등이 추가되면서 이동 방법이 달라진다.

중요한 점은 이동 수단이 단순히 편의 기능으로만 추가되는 것이 아니라, **플레이어가 이전에 겪었던 이동 문제를 해결한다**는 것이다.

처음에는 험한 지형을 직접 걸어야 하지만,

```
도보 이동
→ 장비 사용
→ 차량
→ 도로 및 인프라 구축
→ 이동 효율 증가
```

로 발전한다.

따라서 플레이어는 **같은 지역을 다시 방문하더라도 이전보다 훨씬 효율적으로 이동할 수 있다.**

## 9. 플레이어가 만드는 것은 무엇인가?

데스 스트랜딩에서 플레이어가 만들어내는 것은 단순한 캐릭터 성장만이 아니다.

플레이어는 게임을 진행하면서

- 자신의 이동 경로
- 효율적인 배송 방법
- 화물 운용 방식
- 장비 사용 방법
- 시설 및 인프라
- 다른 플레이어와 공유되는 구조물

등을 만들어낸다.

따라서 플레이어가 만들어내는 것은 **자신만의 물류 네트워크와 이동 전략**이라고 볼 수 있다.

특히 같은 목적지를 가더라도 플레이어마다

> "이 길이 편하다."
>
> "이쪽에 사다리를 설치해두자."
>
> "이 구간은 차량으로 간다."

처럼 다른 해결책을 선택할 수 있다.

## 10. 다른 플레이어의 구조물이 내 플레이를 바꾸는 방식

데스 스트랜딩의 특징적인 시스템은 **비동기 멀티플레이**다.

플레이어가 설치한 사다리, 앵커, 표지판, 구조물, 차량 등의 요소가 다른 플레이어의 게임에 나타날 수 있다.
반대로 다른 플레이어가 설치한 구조물을 자신의 플레이에서 사용할 수도 있다.

이 구조는 중요한 변화를 만든다.

처음에는 플레이어가 혼자서

> "이 산을 어떻게 넘어가지?"

라고 고민하지만, 다른 플레이어가 설치한 사다리를 발견하면

> "이미 누군가 길을 만들어두었네."

라는 식으로 이동 방식이 바뀐다.

즉 **다른 플레이어의 행동이 현재 플레이어의 선택지를 변화시키는 것**이다.

## 11. 비동기 멀티플레이와 플레이어의 행동 순환

이를 구조적으로 보면 다음과 같다.

```
플레이어가 이동
→ 불편한 구간 발견
→ 구조물 설치
→ 다른 플레이어가 사용
→ 이동이 쉬워짐
→ 다른 플레이어가 또 다른 구조물을 설치
→ 새로운 이동 네트워크 형성
```

이 과정에서 플레이어는 단순히 자신의 플레이만 하는 것이 아니라,

> **다른 사람이 이용할 수 있는 환경을 만들어내는 플레이**

도 하게 된다.

또한 다른 플레이어가 자신의 구조물을 이용하고 평가할 수 있다는 점은 플레이어가 구조물을 설치하도록 유도하는 추가적인 동기가 된다.

## 12. 오픈월드에서 이동의 역할을 바꾼 게임

데스 스트랜딩은 기본적인 액션 게임의 틀을 완전히 벗어난 게임이라기보다, **기존 액션 게임의 구조를 사용하면서 액션의 중심 대상을 바꾼 게임**이라고 볼 수 있다.

일반적인 액션 게임에서는

```
이동 → 전투 → 이벤트 → 이동 → 전투
```

처럼 이동이 다음 콘텐츠를 연결하는 역할을 하는 경우가 많다.

반면 데스 스트랜딩에서는

```
이동 → 지형 문제 → 장비 사용 → 경로 선택 → 화물 관리 → 인프라 구축
```

자체가 플레이가 된다.

즉 기존 게임에서 상대적으로 중요하지 않았던 **이동이라는 행동을 주요 게임플레이로 승격시킨 것**이 핵심이다.

## 13. 이동의 반복이 지루하지 않게 되는 이유

단순히 걷기만 반복한다면 이동은 쉽게 지루해질 수 있다.
데스 스트랜딩은 이를 **다양한 요소로 변주**한다.

| 시기 | 이동의 문제 |
|---|---|
| 초반 | 지형과 화물 관리 |
| 중반 | 차량과 장비 |
| 후반 | 도로와 집라인 등 인프라 |

그리고 진행 과정에서 **MULE, BT와의 긴장 및 전투 요소** 등을 삽입한다.

따라서 기본적인 이동이라는 핵심 행동은 유지하면서도, **플레이어가 해결해야 하는 문제가 계속 변한다.**

## 14. 스토리와 배송의 연결

데스 스트랜딩은 단순히 플레이어에게

> "어딘가에 가서 이것을 가져와라."

라고만 요구하는 것이 아니다.

배송 의뢰와 스토리를 연결하고, 배송 이후 의뢰인 NPC가 후일담이나 변화된 상황에 대한 내용을 전달함으로써 **배송이라는 반복 행동에 의미를 부여한다.**

따라서 배송이라는 시스템적 행동과 스토리의 결과가 연결된다.

이는 반복되는 배송에 대한 성취감과 **세계에 기여하고 있다는 감각**을 강화하는 장치로 볼 수 있다.

## 15. 핵심 플레이 루프

데스 스트랜딩의 기본적인 루프를 정리하면 다음과 같다.

```
배송 의뢰 확인
→ 목적지 확인
→ 화물 및 장비 준비
→ 지형 확인
→ 경로 선택
→ 이동
→ 장애물 및 위험 대응
→ 배송 완료
→ 보상 및 성장
→ 인프라 확충
→ 다음 배송의 효율 증가
```

그리고 장기적으로는

```
불편한 이동 경험
→ 문제 발견
→ 장비 / 인프라 확보
→ 이동 방식 개선
→ 더 효율적인 배송
→ 더 큰 배송 및 새로운 문제
```

가 반복된다.

## 16. 오늘의 핵심 발견

데스 스트랜딩에서 가장 인상적인 부분은 **이동을 단순한 연결 과정이 아니라 문제 해결 과정으로 바꿨다**는 점이다.

플레이어는 목적지만 보고 이동하는 것이 아니라,

- 어떤 짐을 가져갈 것인가?
- 어떤 길로 갈 것인가?
- 어떤 장비를 사용할 것인가?
- 위험을 감수할 것인가?
- 싸울 것인가, 피할 것인가?
- 다른 플레이어가 만든 구조물을 이용할 것인가?

를 계속 선택한다.

결국 이동은 단순한 행동이 아니라 **자원 관리와 경로 탐색, 위험 관리가 결합된 게임플레이**가 된다.

## 17. 오늘의 결론

Death Stranding은 기존 액션 게임에서 단순한 이동 과정으로 취급되던 행동을 핵심 게임플레이로 바꾸고, **지형 · 화물 · 장비 · 위험 · 인프라를 결합해 이동 자체를 하나의 문제 해결 과정으로 만든 게임**이다.

또한 플레이어가 자신만의 이동 경로와 인프라를 만들고 이를 다른 플레이어와 공유하게 함으로써, **개인의 이동 경험이 다른 플레이어의 플레이에도 영향을 주도록** 설계했다.

결국 이 게임에서 플레이어가 성장하는 것은 단순한 캐릭터의 능력만이 아니다.

> **"어떻게 운반하고, 어떻게 이동하며, 어떻게 길을 만들 것인가"에 대한 플레이어 자신의 노하우가 성장한다.**

## 오늘의 핵심 인사이트

> **Death Stranding은 '이동'을 다음 콘텐츠로 가기 위한 수단이 아니라, 지형 · 화물 · 장비 · 위험을 해결하는 하나의 핵심 액션으로 만든 게임이다.**
