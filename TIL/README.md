# TIL

날짜별 게임 기획 학습 기록.

## 역할 구분

TIL은 분석 원문을 축약해서 대체하는 문서가 아니다.

| 폴더 | 성격 |
|---|---|
| [GameAnalysis](../GameAnalysis) | 정리된 게임별 분석 (다른 사람이 읽어도 이해되는 형태) |
| **TIL** | 그날 무엇을 분석하고 무엇을 배웠는지의 기록 |
| [StudyLog](../StudyLog) | 정리되지 않은 사고 과정, 실패한 가설, 고민 |

## 작성 형식

```md
# TIL - (게임명) : (그날의 주제)

> 분석 순서: N / 분석일: YYYY-MM-DD
> 관련 분석: [게임명](../../GameAnalysis/게임명.md)

## 오늘의 목표

## (분석 본문)

## 오늘의 핵심 인사이트
```

새 게임을 분석할 때는 [Analysis Framework](../AnalysisFramework.md)의 6단계 절차를 기준으로 작성한다.
