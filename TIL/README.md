# TIL

게임 기획 학습 기록. 하루에 한 게임을 분해하는 훈련의 과정을 남긴다.

이 폴더는 **공부했다는 것을 보여주는 기록**이다.
정리된 결과물은 [GameAnalysis](../GameAnalysis)와 [MechanicStudy](../MechanicStudy)에 있다.

| 구분 | 성격 |
|---|---|
| [GameAnalysis](../GameAnalysis) / [MechanicStudy](../MechanicStudy) | 다른 사람이 읽는 결과물 |
| **TIL** | 그날 무엇을 분석하고 무엇을 배웠는지, 그리고 무엇을 틀렸는지 |

TIL은 분석 원문을 축약한 요약이 아니다.
당일의 사고 과정, 판단이 바뀐 지점, 아쉬웠던 부분을 그대로 남긴다.

### 기록에 대한 메모

- **07-31** — Obra Dinn 분석을 시작했지만 일정 때문에 메모만 남기고 중단했고, 08-04에 본분석을 진행했다.
- **08-04** — Obra Dinn을 마친 뒤 이어서 Baba Is You를 분석해 하루에 두 개를 기록했다.
- **08-06** — Factorio를 마친 뒤 The Witness가 빠진 것을 발견해 같은 날 하나 더 분석했다.
- **08-11** — Hades는 직접 플레이하지 않고 자료를 모아 분석했다. 그래서 문서에 **자료에서 확인한 시스템**과 **그것을 보고 추론한 기획 의도**를 구분해서 적었다.
- **08-12** — 완다와 거상은 과거에 직접 플레이한 게임이지만 기억이 선명하지 않아 문서 위주로 분석했다. 확인되지 않은 부분을 추론으로 채우지 않았고, 그 판단 기준을 **자료 신뢰도 4단계**로 정리했다.
- **08-13** — Devil May Cry 5는 직접 플레이한 적이 없고 관전 기억과 공개 자료로만 분석했다. 전날 정리한 근거 표기(`확인` / `기억` / `추론`)를 분석 문서에 그대로 적용했다.
- **08-14** — Shadow Tactics는 분석을 시작하기 전에 개발사에 대한 평판을 먼저 알고 있었다. 그 정보가 관찰을 한쪽으로 기울게 할 수 있다고 판단해, 개발자 의도를 **관찰 / 설계적 추론 / 외부 근거** 세 단계로 나누는 기준을 만들었다.
- **08-18** — Katana ZERO에서는 제거 후보를 하나 떠올렸다가 **판정을 보류했다.** 근거를 되짚어 보니 기능 분석이 아니라 취향이었기 때문이다. `싫다`와 `기능이 없다`를 분리하는 절차를 먼저 만들고, 결론은 `보류`로 남겼다.
- **08-20** — 몬스터 헌터는 처음에 적은 파밍 루프 위에 **학습 루프가 겹쳐 있다**는 것을 발견하면서 분석의 축이 옮겨갔다. `게임에 어떤 콘텐츠가 있는가`를 나열하는 것에서, `그 콘텐츠를 반복하면서 플레이어가 무엇을 학습하는가`를 보는 쪽으로.
- **08-27** — The Last of Us Part I은 처음 세운 시스템 구조가 **실제 플레이와 어긋난다는 것을 스스로 발견하고 고쳤다.** `탐색 → 전투`로 나눠 놨는데 그 경계가 없었다. 전날 BioShock에서 질문의 순서를 바꿨다면, 이번에는 구조의 경계선을 다시 그었다.
- **08-26** — BioShock Infinite는 어느 항목을 채워도 **스토리와 세계관이 계속 끼어들었다.** 처음에는 분석이 산만한 탓이라고 봤지만, 그 게임의 중심축이 거기에 있다는 신호였다. Outer Wilds 때의 `분석 불가`와 달리 이번에는 **질문의 순서를 바꾸면 되는 경우**였다.
- **08-24** — Dishonored는 **개발자 의도를 확정하지 않는 것**이 목표였다. 관찰과 추론까지만 적고, 외부 근거가 없다는 사실을 문서에 남겼다. 제거 후보로 본 오브젝트 상호작용도 `없어도 되는가`가 아니라 `어디까지 허용할 것인가`의 문제로 바꿔 적었다.
- **08-25** — 히트맨은 전날의 Dishonored와 나란히 놓으면서 차이가 선명해졌다. **악보를 연주하는 것과 피아노로 작곡하는 것**의 차이다. 자유도를 말할 때 `무엇이 자유로운가`까지 적어야 한다는 기준이 여기서 나왔다.
- **08-21** — Sleeping Dogs에서는 제거 후보로 적었던 세 가지를 다시 판정했다. 그러면서 요소를 **핵심 게임플레이 / 성장 시스템 / 공간·세계 경험 / UX / 장식·분위기** 다섯 층위로 나누는 분류표를 만들었다. `없어도 돌아간다`와 `없애도 같은 게임이다`는 다른 문장이다.
